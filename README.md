# sma

Инструмент для прогнозирования биржевых котировок Московской биржи (MOEX): FastAPI-бэкенд
+ HTML/JS-фронтенд на Plotly.js.

Прогноз строится не как точка, а как **полоса неопределённости**, читаемая из взвешенных
квантилей причинно-обрезанного пула похожих исторических событий (каскадный поиск соседей
поверх LP-декомпозиции ряда на детерминированную компоненту + шум). Подробности метода и
вся исследовательская история — в отдельном репозитории
**[sma-research](https://github.com/vinzekatze/sma-research)**.

> ⚠️ **Дисклеймер.** Это исследовательский проект, а не финансовый продукт. Прогнозы не
> являются индивидуальной инвестиционной рекомендацией и не гарантируют результата.
> Данные MOEX ISS API приходят с задержкой ~15 минут. Используйте на свой риск.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
./run.sh
# или вручную:
uvicorn sma.api.app:app --reload --host 0.0.0.0 --port 8000
```

Открыть `http://localhost:8000`.

### Docker

```bash
docker build -t sma .
docker compose up
```

## Загрузка исторических данных

```bash
python -m sma.data.moex SBER --intervals 1d
python -m sma.data.moex SBER GAZP --intervals 1h 10m
```

Данные сохраняются в `data/candles/{TICKER}/{interval}.json` и кэшируются также в
SQLite (`sma.db`, путь настраивается через `SMA_DB_PATH`).
