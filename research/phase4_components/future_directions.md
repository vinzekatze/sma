# Будущие направления исследований

**Дата**: 2026-06-10  
**Контекст**: итог фазы 4 (скр.42–53). Базовый стек стабилен: logtrend + filter bank + LWR(C3-C5) + damped AR(C1-C2) + C0-полоса. Следующие направления — улучшения поверх этого стека.

---

## A. Улучшение прогноза C1/C2

*Текущий результат*: damped AR(BIC), γ_C1=0.5, γ_C2=0.8 → −8.01% MAPE vs slow-only baseline.

### A1. State Space / Dampened Harmonic Oscillator ⭐⭐⭐
**Идея**: C1/C2 — bandpass компоненты с известной центральной частотой ω₀. Моделировать как затухающий осциллятор:
```
[x_{t+1}]   [cos(ω₀)   sin(ω₀)] [x_t  ]
[v_{t+1}] = [-sin(ω₀)  cos(ω₀)] [v_{t}] · e^{-β} + noise
```
Kalman-фильтр оценивает текущие фазу и амплитуду → прогноз = затухающая синусоида с правильной фазой.

**Преимущество перед AR**: использует физическую структуру компоненты (не просто автокорреляционную историю). ω₀ фиксировано из граничных частот фильтрбанка. β — единственный подбираемый параметр.

**Ожидаемый выигрыш**: может превзойти damped AR на C2 (медленная компонента, где фаза устойчива).

---

### A2. ARMA(p,q) вместо AR(p)
**Идея**: causal Butterworth по конструкции вносит MA-структуру в компоненты. BIC-отбор (p, q).

**Ожидаемый выигрыш**: умеренный (+1-3% MAPE) — MA-члены уточняют h=1, не меняя поведение на h>3.

---

### A3. SSA (Singular Spectrum Analysis)
**Идея**: траекторная матрица C1/C2 → SVD → ведущая осцилляторная пара → Recurrent SSA прогноз.

**Преимущество**: не предполагает стационарности (в отличие от Фурье). Работает при медленно меняющейся амплитуде.

**Ограничение**: вычислительно дороже AR. Требует выбора длины окна L.

---

### A4. LWR с малым p на C1/C2
**Идея**: применить LWR (уже реализован для C3-C5) к C1/C2 с p=4-6, xi=21. FNN показал стохастичность, но LWR может поймать локальную персистентность амплитуды.

**Стоимость**: минимальная — весь код есть. Можно исследовать в одном скрипте.

---

### A5. Двухрежимная SETAR по амплитуде
**Идея**: C1/C2 переключаются между режимами нарастания и затухания амплитуды. Порог по `|C_k| / σ_C`. Разные AR-коэффициенты в каждом режиме.

**Ожидаемый выигрыш**: небольшой, но интересен как нелинейное обобщение damped AR.

## B. Улучшение оценки неопределённости C0

*Текущий результат*: σ_C0·√h, rolling window 100 баров, k=1.25 → 80% покрытие. Calibration ratio 1.022 ± 0.143, с систематическим отклонением по h (на h=2-3: +24%, на h=8-10: −18%).

### B1. GARCH(1,1) для σ_C0(t) ⭐⭐⭐
**Идея**: rolling std — запаздывающий оценщик с лагом ~50 баров. C0 вероятно имеет кластеризацию волатильности (ARCH-эффект). GARCH(1,1):
```
σ²_t = ω + α·C0²_{t-1} + β·σ²_{t-1}
```
Даёт динамическую однодневную σ_C0. Полоса расширяется накануне волатильных периодов.

**Ожидаемый выигрыш**: покрытие более стабильно во времени; меньше ложных сигналов в спокойные периоды и реалистичнее в кризисные.

---

### B2. Эмпирическая поправка f(h) ⭐⭐
**Идея**: таблица из скрипта 53 (`ratio[h]` = emp_std / pred_std) даёт систематическую поправку:
- h=2-3: умножить полосу на ~1.24
- h=8-10: умножить на ~0.83

Реализация: интерполяция по таблице `ratio_corr[1..10]` из скрипта 53. Бесплатный прирост точности без новых моделей.

---

### B3. Тяжёлые хвосты — Student-t
**Идея**: Гауссовская σ-полоса недооценивает экстремальные события. Подобрать степени свободы ν к эмпирическому распределению cumsum(C0[:h]) из скрипта 53 → честные 90%+ bounds через t-квантили.

**Особенно важно**: для оценки риска (drawdown), а не только для визуализации.

---

### B4. Блочный bootstrap для асимметричных квантилей
**Идея**: ACF(1)≈+0.12 означает, что i.i.d. bootstrap занижает вариацию. Блочный bootstrap (блок ~8 баров ≈ 1/ACF-decay) сохраняет структуру автокорреляции → точнее эмпирические квантили, возможна асимметричная полоса.

---

### B5. σ_C0 обусловлена рыночной волатильностью
**Идея**: σ_C0 отдельного тикера коррелирует с широкорыночной волатильностью (IMOEX). Внешний регрессор в модели σ → полоса реагирует быстрее rolling window. Требует второго источника данных.
