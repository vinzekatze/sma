## Ключевые выводы

### 1. C0 — чистый шум, не поддаётся прогнозированию

Нулевой прогноз (`ĉ = 0`) является оптимальным для C0 на ВСЕХ протестированных горизонтах. Это подтверждают три независимых теста:
- AR(1) Gain = 0.97 < 1 (−3%)
- OU с теоретическим θ Gain = 0.97 < 1
- OU θ-sweep: Gain > 1 недостижим ни при каком θ — функция монотонно сходится к 1 снизу

**Причина**: ACF[1] = 0.135 даёт R² = 0.018 (1.8% объяснённой дисперсии). Оценка φ по rolling-окну имеет стандартную ошибку ~0.07 → нет статистически значимой предсказательной силы.

### 2. OU модель вырождается в нулевой прогноз

Оптимальный θ для OU = 10 (→ ∞), что означает `ĉ = c[t] × e^{−10} ≈ 0`. Теоретически мотивированный θ=2 даёт Gain=0.968, то есть **хуже** простого нулевого прогноза. Mean-reversion модель бесполезна для C0.

### 3. Persistence катастрофична для C0 и C1

- C0 persistence: Gain = 0.65 (−35%) — вдвое хуже нуля по MAE
- C1 persistence Gain@h=1 = 0.98, но к h=5 → 0.65 (потому что C1 осциллирует с периодом 4–8 bar, persistence к h=5 промахивается на полный период)

Включение C1 persistence в реконструкцию: **+87.2% к MAPE** (катастрофа).

### 4. C1: AR(1) даёт 3%, но на MAPE не влияет

Gain(AR1/zero) @ h=1 для C1 = 1.03. Это статистически значимо (ACF[1]≈0.9 для C1), но в reconstructed MAPE прирост нулевой — c0c1_ar1 даёт +39% из-за разбалансировки.

**Важно**: добавление C1 AR(1) вместе с C0 AR(1) даёт +39%, т.к. AR(1) для C0 (φ≈0.135) при val_h=10 к шагам 3–10 предсказывает значения порядка 0 × 0.135^3 ≈ 0, но до этого успевает добавить ошибку. Это **кросс-компонентный артефакт**: отдельно c0_ar1 ≈ 0%, но в сумме с c1_ar1 +39%.

Причина: ar1 для C1 (φ≈0.90) предсказывает: `ĉ[h] ≈ 0.90^h × c1[0]`. При c1[0] ≠ 0 это добавляет ненулевую экспоненциальную компоненту в dratio_hat, которую cumsum интегрирует → систематическое смещение в r_hat.

### 5. Стандартная стратегия подтверждена и теоретически обоснована

**Оптимальная стратегия**: прогнозировать ТОЛЬКО C3–C5 (LWR), все быстрые компоненты (C0–C2) = 0.

Это не просто эмпирический результат — теоретически обосновано:
- C0 (H=0.28, ACF[1]=0.135): белый шум с лёгкой структурой, R²<2%
- C1 (H=0.32, ACF[1]=0.90): предсказуем в компоненте, но oscillating forecast через cumsum добавляет смещение
- C2 (H=0.39): аналогично C1, oscillating ACF — артефакт фильтра, не рынок

**Вывод скрипта 46**: текущая граница fc_slow=0.0625 (>16 bar) является правильным и оптимальным решением. Нет смысла пробовать улучшать прогноз быстрых компонент.
