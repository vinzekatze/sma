## Ключевые выводы

### 1. MAE компоненты почти не зависит от p

Для всех трёх компонент MAE при h=1 и h=5 практически идентична во всём диапазоне p=4..80. Это означает: **характер прогноза LWR определяется не глубиной вложения p, а геометрией пространства ближайших соседей** (задаётся ξ и формой сигнала).

Причина: медленные компоненты C3–C5 — почти монотонные сигналы. Для них вектор задержки любой длины (4 или 30) одинаково хорошо описывает «уровень и недавний тренд» — дополнительные задержки не добавляют информации.

### 2. Оптимальный p=8 для реконструированного MAPE

**p=8 (uniform) даёт −0.69% к MAPE**. Это неожиданно: меньший p лучше, хотя теоретическое правило `p ≥ T_min/4` требует p≥26 для C5.

Интерпретация — **проклятие размерности**:
- p=20, ξ=63: 20-мерное пространство, 63 соседа → ~3 соседа на измерение (разреженно)
- p=8, ξ=63: 8-мерное пространство, 63 соседа → ~8 соседей на измерение (плотнее)

При меньшем p соседи более «честные» (реально близкие), веса Гаусса более концентрированы. При p=20 большая часть соседей — «почти одинаковые» в среднем, а не «реально похожие по паттерну».

### 3. Per-component p (opt_per) хуже стандарта (+1.00%)

Индивидуально найденные оптимальные p (C3→4, C4→50, C5→16) совместно дают MAPE **хуже**, чем p=20 uniform. Причина: C4 с p=50, ξ=153 требует min_origin=213 точек — это сокращает количество доступных origins в walk-forward. Меньше origins → шумнее оценка MAPE.

### 4. Правило p ≥ T/4 не выполняется эмпирически

Для C5 (T_min=103, p_min_rule=26): MAE при p=10 и p=63 идентичны. Теоретическое правило перегарантировано для очень медленных (слабо осциллирующих) компонент. Для них p=8–16 достаточно.

### 5. Итоговая рекомендация по p

| Конфигурация | MAPE | Рекомендация |
|---|---|---|
| p=20 (текущий стандарт) | 0.01862 | Работает, но не оптимален |
| **p=8 (uniform)** | **0.01850** | **−0.69%, рекомендуется** |
| p=6 | 0.01853 | −0.53%, близко |

Переход с p=20 на p=8 даёт небольшой, но устойчивый выигрыш при ЗНАЧИТЕЛЬНО меньшей вычислительной сложности (меньше итераций в LWR, меньший размер матрицы задержек).
