## 3. Ключевые выводы

### 3.1 Спектральная структура энергии

Энергия dratio распределена крайне неравномерно:
- **83% энергии** в C0+C1 (периоды 2–8 баров)
- **7.7% энергии** в медленных C3+C4+C5 (периоды > 52 баров)

Это подтверждает известный факт: dratio dominated by high-frequency noise. Медленные компоненты, которые мы прогнозируем, несут мало энергии в абсолютных значениях, но являются единственной предсказуемой частью.

### 3.2 Хёрст: «фазовый переход» на ~22–32 барах

Хёрст монотонно растёт с C0 к C5/C11. Критический порог H=0.5:
- **6-band**: пересечение между C3 (H=0.49) и C4 (H=0.63) → граница ~52 баров
- **12-band**: пересечение на C7 (H=0.504) → граница ~22–32 баров

**Интерпретация**: сигналы с периодом < ~25 баров анти-персистентны (mean-reverting), с периодом > ~25 баров — персистентны (трендовые). Это более точная граница, чем та, что следует из 6-band (где она "размыта" широкой октавной полосой C3).

### 3.3 Пермутационная энтропия: непрерывный переход

PE монотонно убывает от 0.990 (C0, максимальная хаотичность) до 0.202 (C5, высокая структурированность). Нет резкого скачка — переход плавный. Это означает, что нет одной "особой" полосы: каждое сужение полосы даёт дополнительную предсказуемость.

### 3.4 C0 — анти-персистентная (mean-reverting)

**Gain < 1 для C0 на всех горизонтах** — LWR хуже нулевого прогноза! Причина: C0 (2–4 bar) имеет H=0.28, т.е. сильную анти-персистентность. После положительного отклонения следует отрицательное. LWR с гауссовыми весами стандартно «предсказывает среднее» и не улавливает mean-reversion.

**Потенциал**: для C0 лучшим прогнозом будет `ĉ = –λ·c[t]` (пропорциональное возврат к нулю). Доверительный интервал может строиться из N(0, σ_C0²).

### 3.5 C1–C2 — осциллирующие ACF (артефакт полосового фильтра)

ACF компонент C1 и C2 демонстрирует затухающие колебания:
- C1: ρ[1]=0.898, затем резкий провал до -0.4 на lag≈4–6
- C2: ρ[1]=0.972, осцилляция на lag≈8–12

Это **стандартный артефакт bandpass-фильтра**: ACF полосового сигнала ≈ затухающий косинус на центральной частоте полосы. Реальной рыночной «недельной периодичности» здесь нет — это свойство фильтра.

**Важно**: высокий ACF1 у C1–C2 (0.9+) не означает предсказуемость в обычном смысле. Это просто корреляция между соседними значениями фильтрованного сигнала (сглаживающий эффект).

### 3.6 C3–C5 — тривиально предсказуемые персистентные компоненты

Gain >> 1 на всех горизонтах. Это объясняется просто:
- Медленный компонент изменяется медленно (H≈0.5–0.83)
- LWR «угадывает» следующее значение как ≈ текущее (persistence forecast)
- Нулевой прогноз (ĉ=0) предсказывает НОЛЬ, игнорируя текущий уровень компоненты

**Эффективный baseline** для медленных компонент — **persistence** (`ĉ[t+h] = c[t]`), не zero.

### 3.7 Сужение полосы (12-band vs 6-band)

12-band **не улучшает** предсказуемость компонент в тех же частотных диапазонах. Gain-числа качественно аналогичны. Однако 12-band даёт:
1. Более точную локализацию «фазового перехода» H=0.5 (22-32 bar vs 52-103 bar)
2. Возможность применять разные методы для узких полос (например, LWR только для C8–C11, другие методы для C0–C7)

**Вывод по H1**: сужение полосы улучшает *понимание* сигнала, но не *качество прогноза* в рамках одного метода (LWR).
