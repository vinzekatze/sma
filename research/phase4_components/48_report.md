## Ключевые выводы

### 1. Ни одна компонента dratio не имеет детерминированного аттрактора

FNN >90% даже при d=30 для всех шести компонент. Это означает: нет низкоразмерного детерминированного аттрактора ни в быстрых (C0–C2), ни в медленных (C3–C5) компонентах — в пространстве задержек dratio.

Это согласуется с фазой 2: Δratio стохастичен по FNN. Фильтрация не создаёт детерминизм из шума.

### 2. Парадокс: медленные компоненты предсказуемы (Gain>>1), но FNN→100%

Противоречие объясняется природой сигнала:

- FNN ищет **детерминированный аттрактор** — геометрическую структуру в пространстве задержек, где близкие точки расходятся по предсказуемому закону
- LWR для C3–C5 работает не через **аттрактор**, а через **персистентность уровня**: медленный компонент меняется настолько плавно, что «следующее значение ≈ текущее» — само по себе хорошая модель
- Это объясняет почему Gain(LWR/zero) = миллионы: zero-baseline предсказывает `ĉ=0`, игнорируя текущий уровень компоненты (≠ 0). Это не интеллектуальная предсказательность, а простое использование инерции.

### 3. C0 — единственный, где FNN убывает (до 43% при d=20)

C0 — широкополосный шум. При увеличении d пространство «раздвигается» и часть ложных соседей отсеивается. Это поведение случайного процесса с некоторой корреляционной структурой (ACF[1]=0.135). Не аттрактор, а эффект размерности.

### 4. Объяснение: почему FNN=100% у медленных компонент

Для C3–C5 (dratio-компоненты) значения экстремально малы (0.8–4.8% энергии). При Theiler=5 исключаем только ближайших 5 соседей по времени. Настоящий ближайший сосед из исторических аналогов — уже «далёкий» по времени. При переходе d→d+1:

- Числитель: |x[t+d] − x_NN[t+d]| ≈ O(σ_component) — компонента чуть изменилась
- Знаменатель: ||X(t)−X_NN(t)|| ≈ O(σ_component * sqrt(d)) — тоже маленький

Отношение ≈ 1/√d × медленно меняющийся фактор → не падает ниже R_tol=10. FNN не обнаруживает структуру, потому что **вся структура — это медленное дрейфование к нулю, а не геометрия аттрактора**.

## Связь с результатами скрипта 47 (p=8 vs p=20)

FNN объясняет, почему MAE компоненты **не зависит от p** (плоская кривая скр.47):

> Если у компоненты нет аттрактора, не существует «правильной» размерности вложения. LWR в любом p-мерном пространстве делает одно и то же — находит ближайших соседей с похожим *уровнем* компоненты и предсказывает следующее значение как взвешенное среднее их следующих значений. При любом p это даёт примерно одинаковый результат.

**Почему p=20 лучше в практике (несмотря на p=8 в скр.47)?**

- Разница p=8 vs p=20 в скр.47 = −0.69% MAPE (в пределах шума walk-forward)
- На практике p=20 даёт более **стабильные и гладкие** прогнозы
- Это объясняется не аттрактором, а **оценкой уровня**: бо́льший p → вектор задержки захватывает больше периодов C3 (T=16..52 bar), что улучшает оценку текущего тренда компоненты
- При p=8 вектор захватывает только полцикла C3 → нестабильнее при обратимых колебаниях
- Практика важнее: **p=20 остаётся стандартом**, результат скр.47 (−0.69%) следует считать шумом

## Итоговая интерпретация LWR на медленных компонентах

LWR работает не как «поиск аттрактора в фазовом пространстве» (что подразумевала бы теория LA/LWR для хаотических систем), а как **локальная регрессия вдоль медленного тренда**:

1. Вектор задержек [c[t], c[t-1], ..., c[t-p+1]] кодирует текущий уровень и локальный наклон медленного компонента
2. Соседи — это исторические моменты с похожим уровнем и наклоном
3. Взвешенная регрессия экстраполирует «как развивался похожий момент»
4. Это работает именно потому, что медленный компонент персистентен: похожие состояния в прошлом → похожее развитие в будущем

Таким образом, LWR выступает как **мягкий нелинейный экстраполятор тренда**, а не как метод реконструкции динамики.
