# Эксперимент 15: Сравнение методов LA — Simplex / LA0 / LWR / RBF

**Тикер:** SBER 10m  |  **T_BIG:** 2%  |  **Дата:** 2026-06-30

---

## 1. Гипотезы

- **Г1**: LWR (LA1, линейная регрессия) лучше Simplex и LA0 (zeroth-order).
- **Г2**: RBF (нелинейный аппроксиматор) лучше линейных методов.
- **Г3**: Оптимальный T_frac ≈ 0.85 × T_BIG = 1.7% (воспроизводится для новых методов).
- **Г4**: Более высокое M (больше лагов) даёт лучший прогноз.

---

## 2. Концепции и обозначения

**Зигзаг T_BIG=2%**: события (пивоты) крупного масштаба, которые прогнозируем.  
**Пул T_frac**: события более мелкого зигзага, используемые как "библиотека прецедентов".  
**Query**: текущий пивот T_BIG, для которого строим прогноз следующего.  
**M**: размерность вложения — сколько последовательных лог-диффов пивотов берём как признаки.  
**K**: число ближайших соседей из пула (по евклидовому расстоянию в пространстве признаков).

### Методы

| Метод | Аппроксиматор | Ядро весов |
|---|---|---|
| **Simplex** | Zeroth-order (взвешенное среднее) | `exp(−d_i / d_min)` |
| **LA0** | Zeroth-order (взвешенное среднее) | Гаусс `exp(−(d/d_max)² / 2)` |
| **LWR (LA1)** | Линейная регрессия | Гаусс `exp(−(d/d_max)² / 2)` |
| **RBF** | Ядровая ridge-регрессия | Гаусс `exp(−d² / (2 d_max²))` |

**RBF детали**: центры = K соседей, Φ_ij = exp(−‖x_i−x_j‖²/(2d_max²)), решаем (Φ+λI)w=y (λ=0.001), предсказываем ŷ = k_query · w.

### Метрика

```
rMAE = mean(|error|) / mean(persistence_errors)
persistence_error[i] = |exp(lp_big[i+1]) − exp(lp_big[i−1])|
```

Persistence baseline: следующий пивот = предыдущий (того же типа) = exp(lp[i−1]).

---

## 3. Методология

Walk-forward: для каждого T_BIG пивота i начиная с i≥max(M, 20):
1. Строим query-вектор: M логдиффов пивотов T_BIG.
2. Каузальный фильтр: пул содержит только события где confirm_date(пивот j+1) < confirm_date(пивот i).
3. Фильтр направления: только события того же типа (HIGH→LOW или LOW→HIGH).
4. Находим K ближайших соседей.
5. Все 4 метода применяются к одному набору K соседей.
6. Ошибка: |exp(lp_big[i] + pred_logdiff) − exp(lp_big[i+1])|.

## 5. Критика постановки

1. **Масштаб признаков не нормализован**: T_frac=1.7% → ходы ~1.7%, T_BIG=2% → ходы ~2%. Расстояния в пространстве признаков смещены на ~18%. Не исправлено — как в предыдущих скриптах.
2. **LWR нестабилен при малом K**: при K=5 и M≥3 линейная регрессия с M+1 параметрами на 5 точках вырождается. Появляются значения ~10^13 и выше. Это загрязняет mean(|error|) для таких комбинаций.
3. **RBF: λ=0.001 — фиксированный компромисс**: при тесно расположенных соседях Φ ≈ I → w ≈ y, предсказания могут выходить за пределы обучающих значений.
4. **Все методы используют одни и те же K соседей**: честное сравнение на равных условиях. Simplex в каноническом варианте требует K=M+1; здесь мы тестируем более общую версию.

## 7. Анализ и выводы

**Г1 ОТКЛОНЕНА**: LWR уступает LA0 при K≥10, где оба метода стабильны.  
**Г2 ОТКЛОНЕНА**: RBF хуже всех методов при всех параметрах (лучшее 0.803).  
**Г3 ПОДТВЕРЖДЕНА**: T_frac=1.7% = 0.85 × T_BIG оптимальна для всех методов.  
**Г4 ОТКЛОНЕНА**: LA0 оптимален при M=3, не при M=5.

### Ключевые наблюдения

1. **LA0 — лучший метод** (rMAE=0.689). Простое взвешенное среднее с Гауссовым ядром по d_max превосходит все варианты.

2. **Усложнение аппроксиматора вредит**: LA0 < LWR < Simplex < RBF по качеству. Чем более гибкая модель, тем хуже. Сигнал слишком зашумлён для линейной или нелинейной регрессии на K соседях.

3. **Различие LA0 vs Simplex**: оба zeroth-order, но разные ядра. LA0 (Гаусс по d_max) устойчивее, чем Simplex (exp(-d/d_min)) — exp(-d/d_min) даёт аномально высокие веса ближайшему соседу при малых d_min.

4. **K=30 лучше везде**: данных в пуле достаточно (2665+ точек доступны к концу ряда), увеличение K за пределы 30 стоит проверить.

5. **LWR нестабилен при K=5, M≥3**: предсказания взрываются (lstsq вырождается). При K≥10 LWR становится стабильным и почти догоняет LA0.

6. **RBF стабилен**, но всегда хуже — kernel ridge regression добавляет дисперсию без полезного смещения.

## 8. Дальнейшие направления

1. **Расширить K**: попробовать K=[30, 50, 75, 100] для LA0 — кривая ещё не вышла на плато.
2. **Нормализация признаков**: поделить query-вектор на T_BIG и pool-вектор на T_frac → одинаковый масштаб. Проверить, даст ли прирост.
3. **LA0 с разными bandwidth**: вместо d_max попробовать d_median или d_mean.
4. **Multi-ticker**: проверить LA0 (T_frac=1.7%, M=3, K=30) на GAZP, LKOH, CHMF, NVTK, PLZL T=2%.
5. **T_BIG=4% и T_BIG=1%**: посмотреть, сохраняется ли T_frac=0.85×T_BIG для LA0.
