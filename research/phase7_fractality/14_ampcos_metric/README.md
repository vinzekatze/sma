# 14 — Метрика amp_cos: влияние на LWR и малые T_frac

## Гипотезы

**H1.** Метрика amp_cos (амплитуда + косинус) в пространстве лог-доходностей даёт меньший rMAE, чем чистый евклид.

**H2.** Косинусная составляющая (форма вектора без учёта масштаба) открывает путь к меньшим T_frac — позволяет находить релевантных соседей среди более мелких событий.

## Концепции и обозначения

| Символ | Смысл |
|---|---|
| `amp_cos` | Метрика из app6: `α·\|log(‖x‖/‖q‖)\|/max_amp + (1−α)·(1−cos∠)/max_cos` |
| `α=0` | Чистый косинус (форма вектора, масштаб игнорируется) |
| `α=1` | Чистая амплитуда (отношение L2-норм) |
| `T_ratio` | T_pool / T_big (масштаб пула) |
| `Euclidean` | Эталон: L2 в пространстве лог-доходностей, rMAE=0.3770 (эксп.13) |

Та же метрика — и для отбора K соседей, и как bandwidth гауссова ядра LWR.

## Параметры

| Параметр | Значение |
|---|---|
| Тикер / интервал | SBER / 10m |
| T_BIG | 0.04 (4%) |
| m | 2 |
| K | 162 (оптимум из эксп.13) |
| Грубый прогон | T_ratio ∈ {0.50,0.60,0.70,0.80,0.85,0.90,1.00} × α ∈ {0.0,0.1,0.3,0.5,0.7,1.0} |
| Тонкий прогон | T_ratio ∈ [0.85,0.95] шаг 0.025 × α ∈ {0,0.005,0.01,0.02,0.05,0.10,0.20} |

## Анализ и выводы

**H1 отклонена.** Лучший amp_cos (rMAE=0.3774) хуже эталона (0.3770) на 0.1% — в пределах шума. Ни один α не даёт статистически значимого улучшения.

**H2 отклонена.** При T_ratio<0.8 результат плохой при любом α. Косинус не компенсирует масштабный разрыв между мелкими событиями пула и крупными событиями запроса.

**Ключевые наблюдения:**

1. **α=0 (чистый косинус) — хуже везде.** В пространстве лог-доходностей масштаб события содержит важную информацию — убирать его нельзя.

2. **Малые α (0.1–0.3) — наименее плохие.** Амплитудная составляющая `|log(‖x‖/‖q‖)|` коррелирует с евклидовым расстоянием и частично воспроизводит его поведение.

3. **Доминирующий фактор — T_ratio, не α.** rMAE определяется масштабом пула, а не выбором метрики.

**Вывод:** евклид в пространстве лог-доходностей — оптимальная метрика для LWR на зигзаге. amp_cos не даёт преимуществ. Вопрос закрыт.
