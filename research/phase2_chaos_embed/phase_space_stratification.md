# Расслоение фазового пространства в методе LA

> Направление исследований, сформулированное 2026-06-08.
> Текущие эксперименты (21–23) тестируют уровень 2 (PE-delay).

---

## Исходная гипотеза

Рыночные котировки стохастичны в глобальном приближении, но их фазовое
пространство является суперпозицией нескольких вполне предсказуемых
хаотических подсистем — по аналогии с «суммой простых волн».

Следствие: LA ищет соседей во всём пространстве задержек и смешивает
векторы из эпох с разными активными подсистемами. Линейная аппроксимация
по такому неоднородному пулу — это усреднение нескольких разных локальных
динамик. Отсюда систематическая ошибка.

---

## Что говорит классический LA

Метод LA (Farmer & Sidorowich 1987; Casdagli 1989; Лоскутов гл. 12–13)
строится на допущении о **единственном** странном аттракторе. Ключевые тезисы:

- Ошибка прогноза растёт как exp(λ(x) · h), где λ(x) — **локальный**
  показатель Ляпунова. Разные зоны аттрактора имеют разную предсказуемость.
- Ложные ближайшие соседи (FNN) возникают при нарушении однородности
  аттрактора, в том числе при **нестационарной смешанной** системе.
- Для смешанной системы «правильный» пул соседей — только векторы из эпох
  с той же активной подсистемой.

Нигде в классическом формализме не предполагается, что аттрактор является
суммой нескольких. Это и есть расширение, которое нужно исследовать.

---

## Математический смысл «суммы подсистем»

Если y(t) = x₁(t) + x₂(t) + ... + xₖ(t), где каждый xᵢ — хаотический
осциллятор с аттрактором Aᵢ, то:

- Пространство задержек содержит суперпозицию всех аттракторов
- Ни один Aᵢ не является инвариантным множеством суммарного ряда
- В разные моменты времени доминирует разная подсистема
- FNN-тест показывает, что размерность аттрактора ratio при p≈4 сходится —
  значит, система **локально детерминирована** в каждый момент. Но какая
  именно подсистема доминирует — меняется.

Косвенное подтверждение: исследование 18/19 показало, что структурные
участки (PE < q25) имеют в 3–4× меньше FNN. Это означает, что в таких
зонах доминирует одна подсистема — и соседи из них принадлежат той же.

## Уровни стратификации фазового пространства

### Уровень 1 — Многомерный вектор режима + кластеризация (GMM)

Для каждого вектора задержек xᵢ вычислять **вектор признаков режима**:

```
regime_vec[i] = [
    PE(window_i),            # информационная сложность
    Hurst(window_i),         # персистентность
    std(Δratio, window_i),   # волатильность
    skewness(Δratio, window_i),
    dominant_freq(window_i)  # через FFT или wavelet
]
```

GMM (k=3–5 компонент) на этих векторах → k «режимов».  
Для текущего query: найти наиболее вероятную компоненту, искать соседей
только среди векторов той же компоненты.

**Это прямая реализация гипотезы** без посредника-PE.

---

### Уровень 2 — PE-пространство задержек (сейчас тестируется, скр. 21–23)

Строить матрицу задержек по **самому PE** с шириной m:

```
P[k] = [bar_pe[k], bar_pe[k+1], ..., bar_pe[k+m-1]]
```

Двухуровневый поиск:
1. Найти ближайших по L2(P) → маска «эпох с похожей историей сложности»
2. Внутри маски — стандартный L2 в x-пространстве

**Отличие от PE-proximity**: ищется похожая *динамика PE*, а не похожий
*уровень PE*. Это улавливает «вхождение в режим» vs «стабильный режим».

Статус: мягкий PE-вес при p=20, α=0.5 даёт −10% MAPE (незначимо, N=200).
Следующий шаг: multi-ticker тест (8 тикеров).

---

### Уровень 3 — Геометрическая кластеризация пула задержек

Прямой **k-means или GMM на строках матрицы X** (или X в PCA-проекции):

```python
gmm = GaussianMixture(n_components=5).fit(X_pca)
labels = gmm.predict(X_pca)
query_label = gmm.predict(vec_pca.reshape(1,-1))[0]
mask = (labels == query_label)
```

Кластеры формируются прямо из **геометрии траектории** — без косвенных
признаков. Кластер = естественная зона аттрактора.

Технически: GMM фитится один раз на всём пуле до внешнего цикла.
PCA уже вычисляется в производственном коде — это его прямое расширение.

**Приоритет: высокий.** Наиболее принципиально-чистый подход.

---

### Уровень 4 — Нелинейное многообразие (UMAP / диффузионные карты)

PCA — линейное снижение размерности. Аттракторы хаотических систем —
изогнутые многообразия. UMAP или диффузионные карты позволяют:

- Разделить несколько перемешанных аттракторов в 2–3D
- Использовать связные компоненты как «подсистемы»
- Визуализировать структуру фазового пространства

Практическая схема:
1. Обучить UMAP на X_pca (pool × k_pca)
2. Кластеризовать DBSCAN в UMAP-пространстве
3. Для query: проецировать, найти кластер, маска

**Приоритет: средний.** Требует sklearn/umap-learn, дороже вычислительно.

---

### Уровень 5 — EMD / VMD-декомпозиция (прямая проверка гипотезы)

**Empirical Mode Decomposition** разлагает сигнал на IMF (Intrinsic Mode
Functions) — буквально «простые волны»:

```python
from PyEMD import EEMD
imfs = EEMD()(dratio)  # shape: (n_imfs, len(dratio))
```

Применение:
- Запустить LA на каждом IMF независимо (каждый со своим optimal p)
- Суммировать прогнозы

Это **прямая операционализация гипотезы** «sum of subsystems».

Известное ограничение: IMF-разложение нестационарно (boundary effects),
рекомбинация может давать drift. Нужно тестировать на walk-forward.

**Приоритет: высокий.** Если работает — прямое подтверждение гипотезы.

## Признаки для разделения подобластей (сводная таблица)

| Признак | Что измеряет | Уровень | Сложность |
|---|---|---|---|
| PE (скаляр) | Информационная сложность | 2 | низкая |
| PE-delay (вектор) | История сложности | 2 | низкая |
| Hurst H | Персистентность | 1 | низкая |
| std(Δratio) | Волатильность | 1 | низкая |
| [PE, H, std, skew] | Многомерный режим | 1 | средняя |
| L2 в X_pca | Геометрия траектории | 3 | средняя |
| Local Lyapunov exp. | Локальная расходимость | 1 | высокая |
| RQA (DET, LAM) | Детерминизм траектории | 1 | высокая |
| IMF амплитуды | Доминирующий осциллятор | 5 | высокая |
| Wavelet energy/band | Доминирующая частота | 1 | средняя |
