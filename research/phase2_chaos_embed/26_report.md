## Ключевые наблюдения

### 1. Тренд подтверждён, но с пиком при k_pca=8

Улучшение растёт от k_pca=3 до k_pca=8, затем спад при k_pca=10.
- При малом k_pca: GMM не видит достаточно структуры (ev=17%)
- При k_pca=8: ev=43% — sweet spot между сигналом и шумом
- При k_pca=10: избыточные компоненты шума разбавляют кластеры

### 2. Hard mode выигрывает при высоком k_pca

При k_pca=8 hard_k5 даёт −9.10% vs soft −1.63%.  
При k_pca=5 hard_k4 даёт −6.87% vs soft −3.78%.  
Интерпретация: в 8D PCA-пространстве GMM находит плотные зоны аттрактора;
жёсткая маска эффективно исключает соседей из чужих зон.

### 3. Одно статистически значимое улучшение

k_pca=10, soft_k4: −5.41%, W-p=0.039 (p<0.05).  
Но это не лучший по медиане результат (−9.10%). Причина несоответствия:
распределение попарных разностей при k_pca=10 soft более сконцентрировано.

### 4. Fallbacks отсутствуют

При всех конфигурациях GMM-кластеры содержат ≥ξ=63 соседей.
d_k на полном пуле — такой же как у baseline.
Проблемы PE-delay (коллапс соседей) нет.

## Интерпретация

GMM в 8-мерном PCA-пространстве (43% ev) разбивает фазовое пространство
delay-матрицы на 5 зон. Поиск соседей внутри зоны query даёт −9%.

Физический смысл: кластеры соответствуют «режимам» рынка — участкам
траектории, где рынок ведёт себя похоже. Внутри кластера соседи
принадлежат той же активной подсистеме → аппроксимация точнее.

## Ограничение

N=200 недостаточно для значимости −9.10% (Wilcoxon p≈0.49).
Оценка необходимого N: при эффекте −9% и наблюдаемой дисперсии
нужно ≈400–600 origins для p<0.05.
