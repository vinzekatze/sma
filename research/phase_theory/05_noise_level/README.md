# T05 — Оценка уровня шума σ_noise через корреляционный интеграл

## 1. Гипотезы

**H1.** Корреляционный интеграл C(m,r) на `ratio` показывает два режима:
- малые r: slope(r) ≈ m (шум заполняет m-мерное пространство равномерно)
- средние r: slope(r) ≈ D₂ ≈ 3–4 (детерминированный аттрактор)

**H2.** Переходная точка σ_noise воспроизводима между тикерами — даёт единый эффективный масштаб шума в сигнале `ratio`.

**H3.** Текущий k=30 при m=9 даёт r_k30 > σ_noise — окрестность LP находится в аттрактор-зоне, а не в шум-зоне. Если нет — k занижен.

## 2. Концепции, терминология, обозначения

| Обозначение | Смысл |
|---|---|
| `ratio` | `close / logtrend` — нормализованная цена |
| `C(m, r)` | Корреляционный интеграл: доля пар точек с расстоянием < r в m-мерном вложении |
| `slope(r)` | Локальный наклон log C / log r — оценка корреляционной размерности на масштабе r |
| `σ_noise` | Эффективный масштаб шума: r*, где slope впервые устойчиво < m−0.5 |
| `шум-режим` | slope ≈ m: шум заполняет m-мерное пространство, аттрактор не виден |
| `аттрактор-режим` | slope ≈ D₂ < m: корреляционная размерность аттрактора стабилизируется |
| `D₂` | Корреляционная размерность аттрактора ≈ 3–4 (из фазы 2 и скр.97) |
| `M_WORK = 9` | Рабочий m LP-фильтра (m = 3·d, d=3) |
| `K_WORK = 30` | Рабочий k LP-фильтра |
| `r_k` | Медиана расстояния до k-го соседа в M_WORK-мерном вложении с Theiler=9 |
| `r_k30/σ_noise` | Ключевое соотношение: > 1 → LP работает в зоне аттрактора |
| `Theiler = m` | Исключаем |i−j| ≤ m при поиске соседей (LP вносит автокорреляцию на ~m баров) |
| `N_REF = 500` | Число опорных точек для оценки C(m,r) |

## 3. Методология и протокол

**Данные:** 8 тикеров MOEX × 1d, logtrend-нормализация (causal OLS).

**Корреляционный интеграл:**
1. Построить матрицу вложения X: (N−m+1, m) с τ=1.
2. Выбрать N_REF=500 случайных опорных точек (seed=42).
3. Для каждой опорной точки: расстояния до всех N точек, исключить |i−j| ≤ m (Theiler).
4. C(r) = доля валидных пар с расстоянием < r.

**r_grid:** адаптивный per-(тикер, m), 60 log-равномерных точек от 0.5-го до 99.5-го перцентиля расстояний в подвыборке 200 точек.

**Slope:** численный градиент log C / log r, сглаженный скользящим средним (окно 7), с пропуском крайних 4 точек.

**σ_noise:** первый r, где slope устойчиво < m−0.5 (=8.5 при m=9) на протяжении N_CONSEC=3 подряд точек.

**r_k:** KDTree на X(M_WORK=9), запрос k+theiler+5 соседей, фильтрация Theiler, медиана k-го расстояния.

## 5. Критика постановки

**5.1 Шум не гауссовский.** GP-метод оценки σ_noise рассчитан на аддитивный гауссовский шум. В финансовых рядах возможны тяжёлые хвосты и мультипликативность. σ_noise — эффективный масштаб, а не истинное σ распределения. Это не делает результат бесполезным, но интерпретацию нужно сохранить осторожной.

**5.2 Переход slope может быть нечётким.** Если аттрактор слаб или шум доминирует на всех масштабах — slope не пересечёт порог 8.5. Такие тикеры получат σ_noise = NaN ("не определён"). Это само по себе диагностически значимо.

**5.3 N_REF=500 вносит случайную вариацию.** Фиксируем seed=42, результаты воспроизводимы. При необходимости воспроизводимость проверяется сменой seed.

**5.4 r_k и σ_noise при одном m.** Оба считаются при M_WORK=9 — это обязательное условие корректного сравнения.

**5.5 Сглаживание slope на краях.** mode='same' в np.convolve даёт артефакты на первых/последних SMOOTH_W//2 точках. Поиск σ_noise начинается после пропуска края.

## 7. Анализ и выводы

**H1 отклонена.** Шум-режим (slope ≈ m = 9) не наблюдается ни на одном тикере ни в одном диапазоне r. Максимальный slope при m=9 составляет 2.15–3.29 — значительно ниже порога 8.5. Корреляционный интеграл `ratio` демонстрирует slope ≈ D₂ = 2–3.5 на всех масштабах в видимом диапазоне.

**Физическая интерпретация.** `ratio = close/logtrend` — медленный, почти детерминированный сигнал. Шум-режим, если и существует, находится на масштабах r < 0.5-го перцентиля расстояний — за пределами разрешения нашего r_grid. Это согласуется с фазой 2: FNN на `ratio` показал аттрактор при p≈4, а `dratio` — стохастичен.

**H2 неопределена.** σ_noise (r* где slope < 8.5) срабатывает сразу после краевого пропуска — не является переходом «шум→аттрактор», а отражает начало стабилизации slope. Значение σ_noise в данном эксперименте технически корректно вычислено, но содержательно интерпретировать как «масштаб шума» нельзя.

**H3 не проверяема в исходной формулировке.** r_k30/σ_noise = 0.86–1.06 выглядит как «граница», но σ_noise здесь — масштаб аттрактора, не шума. Сравнение некорректно.

**Корреляционная размерность D₂.** По стабилизации slope при средних r: D₂ ≈ 2–3.5 для всех тикеров. Согласуется с данными фазы 2 (p_opt ≈ 4 по FNN).

**Методологический вывод.** Оценка σ_noise через GP-интеграл применима только если шум-режим (slope ≈ m) наблюдается в доступном диапазоне r. Для `ratio` этот метод неприменим — нужна прямая оценка через residual LP (→ T05b).
