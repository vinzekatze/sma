# T05b — Прямая оценка σ_noise через residual LP

Дополнение к T05. Дата: 2026-06-19.

## 1. Гипотезы

**H1.** LP-фильтр выделяет значимую часть variance ratio в att: std(noise) << std(ratio).

**H2.** Окрестность LP (r_k при рабочем k) находится существенно выше масштаба шума σ_noise: r_k / σ_noise >> 1. Это означает, что LP ищет соседей в аттрактор-зоне, а не в шумовой.

**H3.** NEW конфиг (d=11, m=33) убирает больше шума, чем OLD (d=3, m=9).

**H4.** Residual noise имеет тяжёлые хвосты (σ_std / σ_mad > 1.0).

## 2. Концепции, терминология, обозначения

| Обозначение | Смысл |
|---|---|
| `ratio` | `close / logtrend` |
| `att` | `local_projective(ratio, m, d, k, n_iter)` — офлайн LP-фильтр |
| `noise` | `ratio − att` — остаточная (шумовая) компонента |
| `σ_std` | `std(noise)` |
| `σ_mad` | `MAD(noise) × 1.4826` — робастная оценка σ при гауссовом шуме |
| `σ_std/σ_mad` | Индикатор тяжёлых хвостов: при гауссовом шуме = 1.0 |
| `r_k` | Медиана расстояния до k-го соседа в m-мерном вложении ratio (Theiler=m) |
| `r_k/σ_std` | Ключевое соотношение: насколько окрестность LP шире масштаба шума |
| **OLD** | d=3, m=9, k=30, n_iter=3 (стандарт до эксп.101) |
| **NEW** | d=11, m=33, k=110, n_iter=2 (лучшая точка эксп.101) |

## 3. Методология и протокол

- Данные: 8 тикеров MOEX × 1d, logtrend-нормализация.
- LP-фильтр офлайн (использует всю историю — не каузален внутри окна).
- σ_std, σ_mad считаются по всему ряду noise.
- r_k считается в m-мерном вложении ratio (рабочий m каждого конфига), Theiler=m, k ∈ {30, 110}.
- ACF noise: лаги 0..40, усреднение по 8 тикерам.
- Корреляционный интеграл на noise: m ∈ {3,6,9,12,15}, N_REF=500, Theiler=m.

## 5. Критика постановки

**5.1 Циклическая зависимость.** σ_noise оценивается через тот же LP, параметры которого проверяем. При заниженном d LP оставляет шум в att → noise завышен. При завышенном d LP убирает часть сигнала → noise занижен. Результат интерпретируем как «σ_noise при данных параметрах», не абсолютную истину.

**5.2 LP офлайн.** Использует будущее в пределах всей истории — σ_noise офлайн оптимистичнее каузального. В production используется rolling LP (каузальный), там σ_noise будет выше.

**5.3 LP вносит автокорреляцию в att на ~m баров** → noise имеет структуру на лагах < m даже при белом исходном шуме. ACF диагностирует это.

**5.4 Метрика r_k — в пространстве ratio, не noise.** r_k считается в m-мерном вложении ratio — это пространство, где LP ищет соседей. σ_noise — масштаб в 1D noise. Соотношение r_k/σ_noise корректно только если noise изотропен в m-мерном пространстве, что для LP-residual не гарантировано.

## 7. Анализ и выводы

**H1 подтверждена.** LP убирает значительную часть variance ratio: σ_std(noise) << σ_std(ratio). Ratio ratio ≈ 0.05–0.09 для всех тикеров.

**H2 подтверждена для обоих конфигов.**
- OLD: r_k30 / σ_std = **3.8–5.2** — окрестность в 4–5 размеров шума. Разумный масштаб: LP работает глубоко в аттрактор-зоне.
- NEW: r_k110 / σ_std = **18.7–27.0** — окрестность в 19–27 σ. Очень широко; потенциальный риск curvature effects (нарушение локальной линейности).

**H3 подтверждена.** NEW убирает на **10–15% больше variance** (σ_std_new < σ_std_old у всех 8 тикеров). Согласуется с лучшим rMAE в эксп.101 (0.327 vs 0.393).

**H4 подтверждена.** σ_std / σ_mad = 1.3–1.9 для обоих конфигов. Noise не гауссовский — тяжёлые хвосты. Особенно выражено у MGNT (1.81/1.86) и VTBR (1.75/1.65).

**Методологическое замечание из T05.** В T05 σ_noise через GP-интеграл давало r_k30/σ ≈ 0.86–1.06. Оказалось, что тот σ_noise — масштаб аттрактора (~0.05–0.09), а не шума. Реальный σ_noise = 0.011–0.019, то есть в 4–6 раз меньше. Методы дают несопоставимые величины.

**Вопрос локальности NEW.** r_k110/σ_std ≈ 19–27 означает, что 110-й сосед при m=33 находится в ~20σ от запроса. Это нарушает предпосылку "локальной" линейной аппроксимации (TISEAN предупреждает о curvature effects при широких окрестностях). Улучшение rMAE в NEW может объясняться эффектом усреднения (больше данных → меньше variance), а не лучшим захватом геометрии аттрактора.

## 8. Дальнейшие направления

- **Проверить локальность k=110 при m=33**: построить временну́е гистограммы индексов 110-го соседа — если они разбросаны равномерно по всей истории, это глобальное усреднение, не локальная проекция.
- **Найти оптимальный k через r_k/σ ≈ C**: теория предполагает оптимум при небольшом кратном σ (например, C=5–10). Для OLD это выполняется при k≈30. Для NEW оптимальный k будет меньше 110 — возможно k=10d с уменьшенным d или k=30d с d=11.
- **Rolling (каузальный) LP**: σ_noise_rolling > σ_noise_offline — насколько больше? Это граница между "что мы показываем" и "что реально используем".
- **Корреляционный интеграл на noise** (рис. D): проверить, виден ли там шум-режим (slope ≈ m), которого не было в ratio.
