# T01 — суррогатный тест: LP создаёт структуру или находит существующую?

## 1. Гипотезы

- **H0_G (null geometry):** d_L(original) = d_L(surrogate) — LP снижает размерность одинаково
  для реального сигнала и его суррогата; структура — артефакт оператора, а не свойство ряда.
- **H1_G (alt geometry):** d_L(original) < d_L(surrogate) — LP находит более низкоразмерную
  структуру в оригинальном сигнале, чем в суррогате. Значит, в ряде есть структура сверх
  того, что сохраняет данный тип суррогата.
- **H0_L (null LWR):** rMAE(original) = rMAE(surrogate) — прогностическая ценность структуры,
  найденной LP, равна нулю; LWR на суррогате предсказывает не хуже LWR на оригинале.
- **H1_L (alt LWR):** rMAE(original) < rMAE(surrogate) — оригинальный att предсказуем лучше,
  чем суррогатный; структура несёт реальную предсказательную информацию.

Нулевая гипотеза H0_FT специфически тестирует: «нет нелинейной структуры сверх линейной
автокорреляции» (FT-суррогат сохраняет спектр мощности, разрушает нелинейность).

## 2. Концепции, терминология, обозначения

- **ratio** — `close / exp(a + b·t)`, logtrend-нормализация по каузальному OLS. Медленно
  осциллирует вблизи 1; стационаризован по тренду.
- **dratio** — `diff(ratio)`, первые разности. Близок к стационарному; стандартный вход LP.
- **att_ratio** — `diff(lp_smooth(ratio))`: стандартный аттрактор-сигнал проекта. LP применяется
  к ratio, берётся разность сглаженного сигнала.
- **att_dratio** — `lp_smooth(diff(ratio))`: LP применяется непосредственно к dratio, без
  повторного дифференцирования. Тестирует, содержит ли dratio собственную аттракторную
  структуру.
- **LP (Local Projective):** итеративная проекция на d-мерное локальное касательное подпространство
  (Grassberger-Hegger). Параметры: m=9, d=3, k=30, n=3 — одинаковые для обоих сигналов.
- **lp_smooth(signal):** LP без финального дифференцирования; возвращает сглаженный сигнал
  той же длины (±1 из-за граничных эффектов).
- **Surrogate** — псевдо-копия сигнала, сохраняющая определённые статистические свойства,
  разрушающая другие (см. таблицу типов ниже).
- **TwoNN d_L** — оценка внутренней размерности (Facco et al. 2017): d = log(2) / E[log(r₂/r₁)].
  Вычисляется на delay-embedding матрице att в p_emb=9 измерениях.
- **p-aligned каскад** — стандарт проекта (скр.93): уровни = p_fit × {1,2,4,...} ≤ p_max.
  p_fit=9, p_max=144 → уровни [144,72,36,18,9].
- **LB-gate** — `d ≥ lb_before_q` на финальном уровне каскада: индикатор надёжности прогноза
  (установлен в экспериментах 101, 109 как устойчивый коррелят точности).
- **abs_error** — |pred_att − true_att|; true_att всегда из ОРИГИНАЛЬНОГО сигнала.
- **rMAE** — mean(abs_error) / std(true_att), нормировано на дисперсию оригинала.
- **Prism G (Geometry):** тест d_L на полной истории, без walk-forward. 99 суррогатов.
- **Prism L (LWR quality):** walk-forward, 20 origins. 19 суррогатов.

### Типы суррогатов

| Тип | Что сохраняет | Что разрушает | H0 которая тестируется |
|---|---|---|---|
| shuffle | маргинальное распределение | всю временну́ю зависимость | «нет ни линейной, ни нелинейной структуры» |
| ft | спектр мощности (линейные корреляции) | нелинейные зависимости | «нет нелинейной структуры» |
| aaft | спектр + маргинальное распределение | нелинейные зависимости | «нет нелинейной структуры» (строже ft) |
| block | локальную автокорреляцию (блоки 20 баров) | глобальный порядок | «нет структуры длиннее 20 баров» |

## 3. Методология и протокол

### Prism G — геометрия att (TwoNN d_L)

Для каждого (ticker, signal, surrogate_type):
1. Взять полную историю `close` (все доступные бары).
2. Вычислить `att_original = build_att(close, signal)`.
3. Для каждого surrogate_idx ∈ 1..99:
   - Построить суррогат input-сигнала (ratio или dratio) на полной истории.
   - `att_surr = build_att_from_surrogate(signal)`.
   - TwoNN d_L на delay-embedding матрице (p_emb=9).
4. Сравнить d_L(original) с распределением d_L(surrogate).
5. p-value = rank(d_L_original среди 1+99 значений) / 100.

### Prism L — предсказательное качество (LWR, walk-forward)

Для каждого (ticker, origin, signal, surrogate_type):
1. `close[:origin+1]` — история без утечки. LP пересчитывается отдельно под каждый origin.
2. `att_original = build_att(close[:origin+1], signal)` — библиотека и вектор запроса.
3. `true_att = build_att(close[:origin+2], signal)[-1]` — истинный следующий шаг **оригинала**.
4. p-aligned каскад → LWR → `pred_original`.
5. Для каждого surrogate_idx ∈ 1..19:
   - Суррогат строится из `close[:origin+1]` (та же история, что для оригинала).
   - `att_surr = build_att_from_surrogate(close[:origin+1], signal, surrogate_type)`.
   - Каскад + LWR → `pred_surr`.
   - `abs_error_surr = |pred_surr − true_att|` (true_att всегда из оригинала).
6. Сравнение: `abs_error_original` vs распределение `abs_error_surr`.

Попутно снимается LB-gate на финальном уровне каскада (для original и surrogate).

**Интерпретация:** если abs_error_surr стабильно превышает abs_error_original —
att несёт предсказательную информацию, недоступную через свойства суррогата.

## 5. Критика постановки

**C1. LP на dratio выдаёт сглаженные разности — другой объект, чем стандартный att.**
att_ratio = diff(LP(ratio)) — это «скорость» сглаженной траектории. att_dratio = LP(dratio) —
сглаженная версия разностей напрямую. Они не эквивалентны, и d_L для них не сравниваются
между собой (только original vs surrogate внутри одного сигнала).

**C2. Суррогат разрушает не только «аттрактор», но и логтренд-нормализацию.**
Shuffle ratio перемешивает бары, нарушая нормировку — de facto возвращает нечто вроде случайного
блуждания вблизи 1. LP на таком сигнале найдёт «структуру» уже из-за того, что все значения
лежат в узком диапазоне. Это занизит d_L суррогатов и завысит значимость. Поэтому суррогат
применяется к уже нормализованному сигналу (ratio или dratio), а не к close.

**C3. Null hypothesis H0_FT = «нет нелинейности сверх линейной».**
Отклонение H0_FT не означает «есть хаотический аттрактор» — это означает лишь, что в ряде
есть нелинейные временны́е зависимости. Тип нелинейности (детерминированная / стохастическая
нелинейность) этим тестом не различается.

**C4. True_att в Prism L из оригинала, pred из суррогата — асимметрия.**
LWR на суррогате предсказывает «следующий шаг суррогата», который сравнивается с «следующим
шагом оригинала». Если средние обоих близки к нулю, abs_error может оказаться мала для
суррогата случайно. Контроль: проверить, что naive baseline (pred=0) хуже и оригинала,
и суррогата.

**C5. Одинаковые LP-параметры для ratio и dratio — не оптимальны ни для одного.**
LP (m=9, d=3, k=30, n=3) отлажен под ratio→diff. Для dratio может быть слишком сильным
(dratio более шумный). Это ухудшит и оригинальный, и суррогатный att одинаково, поэтому
сравнение original vs surrogate остаётся корректным — но абсолютные d_L не оптимальны.

## 7. Анализ и выводы

### 7.1 Гипотеза B (LP создаёт структуру из шума) — **отклонена**

Это главный результат. Если бы LP создавал аттрактор из произвольного ряда, суррогаты
были бы неотличимы от оригинала по качеству LWR. Наблюдаем обратное:

- ratio att: суррогаты ×4.5–45 хуже оригинала (68–98% улучшение, p=0 для всех типов).
- dratio att: суррогаты значимо хуже для shuffle/ft/aaft (22–24%, p=0).

LP раскрывает существующую структуру, не создаёт её.

### 7.2 ratio att — наиболее информативный сигнал

Разрыв между ratio и dratio очень большой: 97% vs 23%.

- **block(20) значимо бит** для ratio att (72.9%, p=0) → структура выходит за горизонт 20 баров.
- **block(20) НЕ бит** для dratio att (2.7%, p=0.174) → dratio-структура локальная (≤20 баров).

Это объясняет, почему стандартный пайплайн (att = diff(LP(ratio))) работает лучше чем
att = LP(dratio): ratio att несёт долгосрочную предсказательную информацию.

### 7.3 Нелинейная структура в dratio подтверждена геометрически

dratio/ft: d_L(original)=4.066 < d_L(FT surr. median)=4.740, **p=0.000**.

FT-суррогат сохраняет спектр мощности, но разрушает нелинейные фазовые зависимости.
После LP-обработки FT-суррогаты имеют БÓЛЬШУЮ размерность, чем оригинал.
Вывод: в dratio есть нелинейная темпоральная структура, не объяснимая одним спектром.

### 7.4 Геометрия ratio att не подтверждает низкоразмерный аттрактор

Для ratio: d_L(original) не ниже d_L суррогатов (все p > 0.34).
Для ratio/block наблюдается обратное: block-суррогаты имеют НИЖЕ d_L (p=0.998).

Этот парадокс объясняется так: LP на коротких блоках (block-суррогат из 20-баровых
фрагментов) создаёт квазислучайный сглаженный сигнал с компактным embedding.
LP на оригинальном ratio проецирует многорежимную структуру → d_L выше.

### 7.5 Ответ на центральный вопрос

**С чем мы имеем дело?**

Данные несовместимы ни с чистым низкоразмерным аттрактором (тогда d_L значимо ниже
суррогатов), ни с чистым шумом (тогда суррогаты были бы не хуже оригинала).

Наиболее согласованная интерпретация — **режимное переключение (Hypothesis C)**:

- В каждом режиме существует локальная детерминированная динамика → LP находит её.
- Несколько режимов с разными касательными подпространствами → интегральная d_L
  не снижается (суррогаты сопоставимы геометрически).
- Режимы длиннее 20 баров → block суррогат не воспроизводит структуру (ratio/block бит).
- Внутри режима паттерны повторяются и не устаревают (temporal decay отклонён скр.82) →
  LWR находит их через паттерн-матчинг.

LB-gate (d ≥ LB) работает как детектор «текущий origin глубоко внутри одного режима»:
при ratio/original gain=29% (несмещённая тенденция, мощности 80 origins не хватает).

### 7.6 Уточнение ранее сделанного вывода

Ранее из наблюдения «TwoNN d_L: dratio→57, att→7.72» был сделан вывод «LP создаёт
аттрактор, не обнаруживает». Суррогатный тест показывает, что это верно лишь частично:
LP действительно снижает d_L любого сигнала (эффект сглаживания), но оригинальный ряд
несёт дополнительную структуру, которую LP раскрывает и которую нельзя воспроизвести
через суррогаты. Правильнее: **LP одновременно сглаживает И раскрывает** — и оба эффекта
присутствуют, однако прогностически значима именно раскрытая структура.

## 8. Дальнейшие направления

- **Синтетическая верификация (T02):** повторить тест на AR(1)/GARCH синтетике.
  Если GARCH-суррогат LWR ≈ original → ряд объясним GARCH-моделью без аттрактора.
  Если GARCH-суррогат значимо хуже → есть структура, не объяснимая GARCH.

- **Размер блока:** block_size=20 не бит для dratio. Проверить block_size ∈ {5,10,33,50}
  для ratio: при каком размере блока теряется предсказуемость? Это даст оценку
  характерной длины режимов.

- **Более длинная история:** LB-gate для ratio/original: p=0.127, n_true=29.
  С 200 origins (4 тикера × 50) можно получить достаточную мощность.

- **dratio как per-origin признак:** dratio-структура локальна (≤20 баров, block не бит).
  Это может быть полезно как признак «свежей» динамики для адаптивного выбора параметров.

- **Геометрия dratio/ft (p=0.000):** единственный значимый Prism G результат — нелинейная
  структура в dratio. Её связь с LB-gate и oracle_p неизвестна.
