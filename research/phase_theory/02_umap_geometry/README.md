# T02 — UMAP-геометрия пространства задержек att

## 1. Гипотезы

- **H1:** Пространство задержек att (после LP) имеет нетривиальную геометрическую структуру — в отличие от пространства задержек raw dratio (шум заполняет пространство равномерно).
- **H2:** При больших p (144, 288) — размерах верхнего уровня каскада — att лежит на низкоразмерном многообразии. LP(d=3) и LP(d=11) описывают многообразия разной размерности.
- **H3:** Локальная размерность (LB) пространственно неоднородна: регионы UMAP, соответствующие разным «режимам», имеют разный LB — это геометрический след режимного переключения.
- **H4:** UMAP для att устойчив к случайному seed, для raw dratio — нет (структуры нет — нечего воспроизводить).

## 2. Концепции, терминология, обозначения

- **att = diff(LP(ratio))** — стандартный аттрактор-сигнал. LP-фильтр применяется к ratio, берётся первая разность.
- **dratio = diff(ratio)** — первые разности без LP. Контроль: показывает геометрию без фильтрации.
- **ratio = close / logtrend** — уровень, без LP, без diff. Контроль: медленный дрейф → артефакт нестационарности.
- **LP(m, d, k, n)** — Local Projective filter. m — размер окна задержек, d — размерность проекции, k — соседей, n — итераций.
- **p_emb** — размерность delay-embedding: каждая точка = [att(t), att(t-1), ..., att(t-p+1)].
- **LB (Levina-Bickel)** — локальная оценка внутренней размерности для каждой точки матрицы задержек: `d_LB = (k-2) / Σ log(r_k / r_j)`, k_max=8.
- **CV** — коэффициент вариации LB = std/mean. Мера гетерогенности многообразия.
- **gap** — отношение max/min средней LB по k=4 кластерам UMAP (k-means). Мера пространственной неоднородности LB.
- **stab r** — Spearman-корреляция между матрицами попарных расстояний для seed=0 и seed=42 (subsample N=1000). stab→1 означает, что UMAP воспроизводит одну и ту же геометрию.
- **r(LB, t)** — Spearman-корреляция между LB и временны́м индексом. Отрицательный → LB убывает со временем (аттрактор «упрощается»).

## 3. Методология

Для каждого (ticker, variant):
1. Вычислить сигнал (att / dratio / ratio) по полной истории (офлайн, без walk-forward).
2. Построить delay-matrix X: (N - p_emb) × p_emb.
3. Вычислить LB в каждой точке: KDTree, k_max=8 соседей.
4. Применить UMAP (seeds=0, 42, 123), n_neighbors согласно варианту, min_dist=0.1.
5. Визуализировать: Row 0 — seed=0 × [время | LB | |att|], Row 1 — устойчивость seeds.
6. Количественный анализ: LB-статистика, r(LB,t), gap, stab r.

Тикеры: SBER, MRKP, CHMF, NVTK (1d). ~4500–5350 баров каждый.

## 5. Критика постановки

**C1. LP офлайн — не то же пространство, что при реальном прогнозе.**
LP здесь пересчитывается на полной истории (нонкаузален через весь ряд). При прогнозе LP пересчитывается на `close[:origin+1]`. Геометрия видна, но она идеализирована.

**C2. LB с k=8 — грубая оценка для высоких d.**
При p=288 (вариант H/J) k=8 ≪ d → LB занижена систематически. Относительные сравнения между вариантами корректны, абсолютные значения при высоких p — нет.

**C3. UMAP не сохраняет глобальные расстояния.**
stab r измеряет локальную консистентность (попарные расстояния), а не глобальную ориентацию. Отражения/повороты не обнаруживаются.

**C4. ratio — нестационарен, результаты E и F частично артефактны.**
LB≈4 для F объясняется slow drift, а не аттрактором. gap=1.54 для F — неслучаен, но интерпретируется как структура дрейфа, не динамики.

**C5. Кластеризация k-means на UMAP-координатах зависит от UMAP.**
Пространственный gap LB измерен через UMAP-проекцию, а не напрямую в p-мерном пространстве. При нестабильном UMAP (D: stab=0.45) gap = артефакт.

## 7. Анализ и выводы

### 7.1 H1 подтверждена: att имеет структуру, dratio — нет

dratio (D): stab=0.45 (UMAP случаен), LB med=25 (высокоразмерный шум).
att (A, B, G, H, I, J): stab=0.78–0.97, LB med=3–7 (структурированное многообразие).
Разница однозначна и согласуется с суррогатным тестом T01 (H_B отклонена).

### 7.2 H2 подтверждена: att ложится на низкоразмерное многообразие при больших p

LP(d=3) — самосогласованность:
```
p=9   → LB=4.4
p=33  → LB=7.0   (пик — смешение коррелированных и независимых лагов)
p=144 → LB=3.3   (LP автокорреляция доминирует, аттрактор ≈3D)
p=288 → LB=2.8   (устойчивая точка ≈3 = LP_D)
```
LP(d=3) «сжимает» att до 3D на крупных масштабах. LP(d=11) сохраняет больше сложности:
```
p=33  → LB=7.0
p=144 → LB=5.2
p=288 → LB=4.8   (устойчивая точка ≈5 > LP_D=3)
```
LP(d=11) описывает 5D-многообразие при p=288 — богаче, чем 3D у LP(d=3).

**Практический вывод для каскада:** на первом уровне каскада (p=288) att d=3 лежит на
3D многообразии в 288D пространстве. Каскад геометрически мотивирован: стартует с
однородного 3D пространства (CV=0.19), уточняет к гетерогенной локальной структуре (CV=0.47).

### 7.3 H3 подтверждена частично: пространственная неоднородность реальна

Максимальный gap при att: I=1.17, J=1.17, B=1.11. LP(d=11) даёт более выраженную
пространственную гетерогенность LB на UMAP — больше «режимов».
LP(d=3) при p=288 (H): gap=1.06 — почти гомогенный.

**Вывод:** LP(d=11) при средних p (33–144) создаёт наиболее контрастную
режимную геометрию. Это объясняет, почему d=11 лучше в LB-gate экспериментах (101+):
пространственная гетерогенность → gate более информативен.

### 7.4 H4 подтверждена: устойчивость UMAP коррелирует со структурой

D (dratio, нет структуры): stab=0.45 ← UMAP случаен.
F (ratio, trend-driven): stab=0.98 ← UMAP тривиально устойчив (дрейф детерминирован).
att: stab=0.78–0.97 ← реальная, воспроизводимая геометрия.

### 7.5 Неожиданный результат: r(LB, t) < 0 во всех вариантах

Все att-варианты показывают отрицательную корреляцию LB с временем (r от -0.03 до -0.39).
Локальная размерность многообразия **убывает** к концу истории — динамика «упрощается».

Эффект усиливается с p: при p=288 r≈-0.35...-0.39 (статистически значимо при N≈4500).
При p=9 r≈-0.03 (слабо, почти не видно).

Возможные объяснения:
1. **Структурный сдвиг рынка**: после 2014/2022 российский рынок уменьшил количество
   торгуемых инструментов и торговых игроков → динамика стала проще.
2. **Эффект длины истории**: чем больше истории, тем стабильнее LP строит аттрактор.
   Недавние точки имеют меньше «ретроспективы», LP менее надёжен.
3. **Нонкаузальность LP** (артефакт): LP видит всю историю до конца ряда.
   Недавние точки проецируются лучше, так как окружены меньшим количеством
   «будущих» точек от которых они отличаются → может занижать LB.

Требует отдельного исследования (например, rolling LP, честный каузальный вариант).

### 7.6 ratio: артефакт нестационарности виден явно

F (ratio p=33): подкова в UMAP, stab=0.98, gap=1.54 (самый высокий!) — но это
структура дрейфа, не аттрактора. Time-панель показывает монотонный градиент от края до края.
LB=4.2 у F ниже, чем у att (G=3.3 похоже, но по другой причине: at G это
истинное 3D многообразие). Использование ratio для embedding по-прежнему нецелесообразно.

## 8. Дальнейшие направления

- **Rolling LP (каузальный):** пересчитать UMAP с LP, ограниченным текущим окном.
  Проверить, исчезает ли r(LB,t) < 0 — если да, это артефакт нонкаузальности.
  
- **Геодезическое расстояние (T03):** вместо Euclidean в p-мерном пространстве
  использовать Isomap/geodesic → более точный поиск соседей LWR.
  
- **LB как per-origin признак:** с LB-картой UMAP проверить, предсказывает ли LB
  в конкретной точке качество прогноза LWR. Если да — использовать как gate.
  
- **Сравнение d=3 vs d=11 при равном p:** запустить B-аналог при p=9 (d=11,m=33,p=9)
  и проверить, даёт ли LP(d=11) лучшую геометрию уже при малом p.
