## Почему не работает: диагностика std медленных компонент (SBER)

| Метод | slow C3-C5 std | Отношение к dratio |
|---|:---:|:---:|
| dratio (baseline) | 0.005894 | 1.0× |
| **d²ratio** | 0.000758 | **0.129×** ← overdifferencing |
| z(win=10..100) | 0.260–0.278 | **44–47×** ← overshooting |

**Z-score раздувает медленные компоненты в 44–47 раз** по сравнению с dratio.

### Механизм раздувания

`z[t] = dratio[t] / sigma[t]` где `sigma = rolling_std(dratio, win)`.

Когда dratio движется в одном направлении несколько баров (медленный тренд), его rolling_std мала (небольшой разброс вокруг ненулевого среднего). В результате `z[t]` принимает большие значения. Медленная компонента z ≈ «тренд dratio относительно его локальной волатильности» — гиперболизирует тенденцию.

Итог: LA ищет соседей в пространстве 44× увеличенных значений. Паттерны стали «громче», но не чище.

## Ключевой вывод о природе проблемы

Нормализация до filter bank (как d²ratio или z-score) **не улучшает** качество LA на медленных компонентах:

| Подход | slow std | Механизм | Результат |
|---|:---:|---|:---:|
| dratio | 1× | — | baseline −22% |
| d²ratio | 0.13× | overdifference → потеря структуры → мартингал | −33% (но прямая линия) |
| z-score dratio | 47× | раздувание тренда → шум маскирует паттерны | ~0% |

**Фундаментальный вопрос переформулируется:** filter bank на dratio уже выделяет медленные компоненты. Проблема не в нормализации ДО filter bank, а в том, что медленные компоненты dratio **нестационарны по амплитуде**: в трендовые периоды amplitude C3-C5 большая, в боковые — малая. LA путает «похожие по форме, но разные по амплитуде» паттерны.

## Новая гипотеза: нормализация ПОСЛЕ filter bank

**Скр.40**: нормировать каждую медленную компоненту по отдельности ПОСЛЕ filter bank.

```python
# После make_filter_bank(dratio):
comp_ci_raw = comp[ci]                                   # C3, C4, C5
sigma_ci    = rolling_std(comp_ci_raw, win)              # локальная амплитуда компоненты
comp_ci_z   = comp_ci_raw / (sigma_ci + eps)             # нормировать
# LA на comp_ci_z → z_hat[ci]
# Реконструкция: comp_hat[ci] = z_hat[ci] * sigma_ci[origin_k]
# dratio_hat = sum(comp_hat) → ratio[origin] + cumsum(dratio_hat)
```

Почему это лучше:
- Нормировка происходит в пространстве МЕДЛЕННЫХ компонент (уже выделены)
- Устраняет amplitude non-stationarity МЕДЛЕННОЙ части
- Реконструкция масштабирует обратно на актуальную амплитуду при origin_k
- Медленная структура сохраняется полностью (std не падает до 0.13× и не вырастает до 47×)
