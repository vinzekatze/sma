## Что проверялось

Замена `dratio = diff(ratio)` на `drcycle = diff(hamilton_cycle(ratio, h))`:
- `hamilton_cycle = ratio - OLS(ratio[t] on ratio[t-h..t-h-3])`
- Цикл уже центрирован (OLS остаток), diff убирает медленный дрейф
- h ∈ {5, 10, 20} (неделя, 2 недели, месяц в дневных барах)

Также проверен rcycle (цикл без diff) — предсказуемо плохо (аналог ratio-mode из скр.9).

## Интерпретация

**Почему Hamilton(h=5) + diff работает:**

`hamilton_cycle = ratio - OLS(ratio[t] on ratio[t-5..t-8])`

OLS вычитает предсказуемую компоненту с лагами 5-8 дней (недельная авто-корреляция). Остаток содержит:
- Медленные компоненты, которые не предсказываются через недельные лаги
- Быстрые компоненты (шум)

После diff(cycle) убирается медленный дрейф. Итого: `drcycle` — более "очищенный" сигнал, где недельная предсказуемая компонента вычтена аналитически, а не через filter bank. Filter bank получает лучше разделённые частотные компоненты.

**Почему h=5 лучше h=10,20:**

При малом h (5 дней) Hamilton убирает только ближние лаги → filter bank получает более широкий спектр. При h=20 Hamilton слишком агрессивно убирает компоненты, которые нужны LA для прогноза.

**Почему rcycle без diff плохо:**

Hamilton cycle на ratio не является нулевым в среднем (медленный тренд ratio остаётся). Без diff LA ищет соседей по абсолютному уровню — аналог ratio-oneshot (скр.9).
