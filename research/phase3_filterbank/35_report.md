# Отчёт 35: Fractional Differencing как нормализация перед filter bank

**Результат: гипотеза не подтверждена. fd(ratio, d<1) хуже dratio на 33–75%.**

---

## Что проверялось

Замена `dratio = diff(ratio)` (d=1) на `fd = fracdiff(ratio, d_min)` где d_min ∈ (0,1) — минимальное d, при котором ADF отвергает единичный корень. Гипотеза: сохранение долгосрочной памяти улучшит LA при поиске соседей.

## Диагностика: почему провал

**Причина 1: ненулевое среднее fd.**

`ratio ≈ 1.0` (осциллирует вокруг 1 из-за SMA нормализации). При d=0.3:
```
fd_mean ≈ 0.154,  fd_std ≈ 0.073
dratio_mean ≈ 0.0,  dratio_std ≈ 0.023
```

LA/LWR ищет соседей через L2-норму в delay-space. При нецентрированном fd соседи определяются уровнем тренда, не формой паттерна — это эквивалентно поиску соседей по ratio напрямую, что было плохо в скр.9 (ratio-oneshot).

**Причина 2: длина весов fd.**

При threshold=1e-4: len(w) = 200–503 для d=0.1–0.5. Первые ~300–500 значений fd = NaN. Скрипт корректно обходит это через `min_orig_fd`, но это сужает walk-forward окно.

**Причина 3: filter bank + нетрендовые данные.**

С5 компонента fd (медленный тренд) имеет значения ≈ 0.169 — это тренд ratio, а не осцилляция. LA пытается предсказать медленный дрейф абсолютного уровня fd, а не локальную динамику.

## Вывод

**Fracdiff (d<1) как замена dratio не подходит для LA/LWR**, потому что fracdiff(ratio) не является центрированным и стационарным в нужном смысле. dratio (d=1) обеспечивает:
- Нулевое среднее → соседи в delay-space ищутся по форме паттерна, не по уровню
- Стационарность → LA находит фазово-похожих соседей

Идея сохранения долгосрочной памяти через d<1 противоречит требованиям LA к входному ряду.

## Что делать дальше

1. **Hamilton Filter** (скр.36) — более точная оценка тренда для получения лучшего "цикла":
   `hamilton_cycle = close - hamilton_trend` вместо `ratio = close / SMA`
   Цикл Hamilton'а уже центрирован и стационарен — дополнительное дифференцирование может не потребоваться.

2. **Rolling Z-score нормировка** (скр.37) — добавить нормировку волатильности поверх dratio:
   `z_dratio = dratio / rolling_std(dratio, W)` 
   Цель: сделать октавные полосы filter bank равномерными по энергии.

Fracdiff остаётся полезным инструментом для **статистической характеризации** ряда (d_min как мера долгосрочной памяти), но не как нормализация для LA.
