## Диагностика механизма

### Почему AR порядок не важен?

AR(1) при h=1 имеет `b ≈ 0.997`, R² ≈ 0.994. AR(4) добавляет R² = 0.00001. Ratio — почти чистое случайное блуждание, AR(1) объясняет 99.4% дисперсии. Лишние лаги дают нулевой вклад.

### Что такое diff(hcycle)?

При `b ≈ 0.997`:
```
diff(hcycle[t]) = ratio[t] - (1+b)*ratio[t-1] + b*ratio[t-2]
               = dratio[t] - b*dratio[t-1]
               ≈ dratio[t] - 0.997*dratio[t-1]
```

Это **почти идентично d²ratio** = `dratio[t] - 1.000*dratio[t-1]`. Разница в коэффициенте 0.003 × std(dratio) ≈ 7e-5 — пренебрежимо мала.

### Откуда тогда улучшение в −14%?

Ключ — **способ реконструкции**, а не фильтрация сигнала.

| Метод | Реконструкция | Δ% |
|---|---|:---:|
| d²ratio + двойной cumsum | `dratio[origin] + cumsum(d2hat)` → `ratio[origin+1] + cumsum(...)` | **+73%** |
| AR-whitening (оригинал) | `hcycle[origin] + cumsum(dhcycle_hat) + htrend[origin]` | **−14.27%** |
| d²ratio + однократный cumsum | `ratio[origin] + cumsum(d2ratio_hat)` | **−14.26%** |

Корреляция ошибок AR vs d²ratio_single = **0.9998** — практически идентичны.

**Итог:** AR-whitening математически эквивалентно:
1. Взять d²ratio = diff(diff(ratio))
2. Подать в filter bank
3. При реконструкции: `ratio_hat = ratio[origin] + cumsum(d2ratio_hat)` (один cumsum!)

Двойной cumsum накапливает ошибки прогноза дважды → провал. Однократный cumsum использует `ratio[origin]` как якорь → стабильно.

## Финальная архитектура (упрощённая)

```python
# Нормализация (без изменений)
ratio  = close / SMA(1000)
dratio = np.diff(ratio)

# Новое: второе разностное
d2ratio = np.diff(dratio)   # ← одна строка вместо Hamilton OLS

# Filter bank (без изменений)
COMP = make_filter_bank(d2ratio)

# Прогноз (без изменений)
hat = sum_lwr_on_slow_components(COMP)  # d2ratio_hat

# Реконструкция — ВАЖНО: один cumsum от ratio[origin]
ratio_hat = ratio[origin] + np.cumsum(hat)   # ← не двойной cumsum!
price_hat = ratio_hat * MA[origin]
```

AR(4)-whitening = идентичный результат, но требует OLS. Достаточно `np.diff(dratio)`.
