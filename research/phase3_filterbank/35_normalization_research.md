# Исследование 35: Методы нормализации перед полосовыми фильтрами

**Дата:** 2026-06-09  
**Контекст:** После подтверждения эффективности filter bank (−22% MAPE, скр.34), изучаем входной сигнал. Текущая нормализация `ratio = close / SMA(1000)` использует SMA — грубый ФНЧ с плохой частотной характеристикой. Цель: найти нормализацию, которая даёт более стационарный и информативный сигнал для filter bank.

---

## Текущая схема

```
close → ratio = close / SMA(1000) → dratio = diff(ratio) → filter bank (Butterworth) → LA/LWR
```

SMA выполняет две задачи: **оценка тренда** и **масштабирование**. Проблемы:
- SMA сам по себе ФНЧ с медленным спадом и боковыми лепестками
- Не нормирует гетероскедастичность (изменение волатильности во времени)
- `dratio = diff(ratio)` — дифференцирование d=1, уничтожает долгосрочную память

---

## Категория 1: Улучшенная оценка тренда

### 1.1 Hamilton Filter (2018)

Регрессия текущей цены на значения с лагом `h`:
```
y[t] = α + β₁·y[t-h] + β₂·y[t-h-1] + β₃·y[t-h-2] + β₄·y[t-h-3] + ε[t]
```

Тренд = fitted values, цикл = остаток `ε[t]`. Для 1d баров: `h=8..12`.

**Плюсы:** строго causal, нет end-effect (в отличие от HP), математически обоснован как замена HP-фильтра. Цикл Hamilton'а уже стационарен с нулевым средним — подаётся в filter bank без дополнительного дифференцирования.  
**Минус:** нужно подбирать `h`.

### 1.2 HP Filter (Hodrick-Prescott) — ❌ запрещён

Минимизирует `Σ(y − trend)² + λ·Σ(Δ²trend)²`.  
**Двусторонний (non-causal)** — тренд в момент `t` зависит от будущих значений. Аналог `sosfiltfilt`. Нельзя применять в walk-forward.

### 1.3 Rolling polynomial regression

Rolling OLS-регрессия `close(t)` на `[1, t, t²]` в окне `W`. Лучше улавливает ускоряющиеся тренды, но требует выбора степени и окна.

## Категория 2: Нормализация по волатильности

SMA убирает тренд, но не нормирует **гетероскедастичность**. Это нарушает равномерность энергии по октавным полосам filter bank.

### 2.1 Rolling Z-score

```
z[t] = (ratio[t] - mean(ratio, W)) / std(ratio, W)
```

Ряд становится приближённо стационарным **и** нормированным по дисперсии. `W_inner` должно быть меньше `MA_WINDOW` (напр., 100–200 при MA=1000).

### 2.2 ATR-нормализация

```
norm[t] = (close[t] - close[t-1]) / ATR[t]
```

Возвраты, нормированные на текущую волатильность. Полностью убирает ценовой уровень, работаем только с возвратами.

### 2.3 Percentile rank (rolling) — ❌ не подходит для filter bank

Нелинейное преобразование нарушает аддитивность суперпозиции частот.

## Категория 3: Fractional Differencing ⭐⭐ [Приоритет #1]

### Проблема `dratio = diff(ratio)` (d=1)

Обычное дифференцирование убирает единичный корень, но **уничтожает долгосрочную память** ряда (autocorrelation быстро затухает → LA не видит отдалённых аналогов).

### Решение: дробное дифференцирование `d ∈ (0, 1)`

(Лопес де Прадо, *Advances in Financial Machine Learning*, гл. 5)

Веса по биному Ньютона:
```
w_0 = 1
w_k = -w_{k-1} · (d - k + 1) / k
```

Оператор:
```
y_d[t] = Σ_{k=0}^{T} w_k · y[t-k]
```

Алгоритм:
1. Взять `ratio` (не `dratio`)
2. Найти минимальное `d` при котором ADF-тест отвергает единичный корень (p < 0.05)
3. Применить fractional differencing с этим `d`
4. Результат подать в filter bank вместо `dratio`

**Почему важно для нас:**
- При `d ≈ 0.3–0.5` ряд стационарен, но сохраняет долгосрочную автокорреляцию
- Filter bank получает более информативный сигнал с богатой структурой
- LA/LWR при поиске соседей находит исторически аналогичные фазы, а не случайный шум

**Реализация:** ~30 строк кода, строго causal по построению.

## Категория 4: Разложение вместо нормализации

### 4.1 MODWT (Maximal Overlap DWT)

Нормировка встроена в вейвлетные базисные функции. Causal, любая длина входа. Честный конкурент Butterworth filter bank, а не нормализация перед ним.

### 4.2 SSA (Singular Spectrum Analysis)

Рассматривался в скр.31, конвергировал с filter bank. Разлагает матрицу задержек через SVD — тренд и осцилляции без явной нормализации.

### Скрипт 35: Fractional Differencing [в работе]

**Гипотеза:** `fd_ratio` при оптимальном `d` (ADF-минимальное) + filter bank даст меньший MAPE, чем текущий `dratio` + filter bank.

**Протокол:**
1. Вычислить `ratio = close / SMA(1000)` (как сейчас)
2. Найти минимальное `d` через ADF sweep `d ∈ {0.1, 0.2, ..., 1.0}` на train-части
3. Применить fractional differencing → `fd_ratio`
4. Подать `fd_ratio` в `forecast_fb()` вместо `dratio`
5. Walk-forward на тех же 8 тикерах, что и скр.34
6. Сравнить MAPE: fd_ratio vs dratio vs ratio (текущие)

**Ожидаемый результат:** дополнительное снижение MAPE поверх filter bank.

### Скрипт 36: Hamilton Filter [следующий]

**Гипотеза:** Hamilton-цикл как вход в filter bank лучше `ratio`, потому что тренд удалён точнее.

### Скрипт 37: Комбинация Hamilton + Z-score [следующий]

Hamilton убирает тренд, Z-score нормирует волатильность. Совместно: `hamilton_cycle[t] / rolling_std[t]`.
