# Zigzag Dir-Split: раздельные модели up/down для зигзаг-S-map

## 1. Гипотезы

- Г1: Обучение только на пивотах того же направления (same_dir) улучшает rMAE по сравнению с базой (base = весь пул).
- Г2: Модель на противоположных направлениях (opp_dir) хуже базы — санити-чек, что направление несёт информацию.
- Г3: same_dir снижает H3-асимметрию (bias_H − bias_L уменьшается).
- Г4: p=3 улучшает прогноз по сравнению с p=2.

## 2. Концепции, терминология, обозначения

- **Пивот** — подтверждённый экстремум зигзага (T=2%).
- **Направление (dir)**: 'H' — пивот выше предыдущего (хай), 'L' — ниже (лой).
- **base** — тренировочный пул без фильтрации по направлению.
- **same_dir** — пул ограничен пивотами того же направления, что и шаг прогноза.
- **opp_dir** — пул ограничен пивотами противоположного направления.
- **p** — размерность пространства задержек; признаки: `[z[i], Δz[i], ..., Δz[i-p+2]]`.
- **H3-асимметрия**: систематическое различие bias_H (прогноз хая → следующий лой) и bias_L (прогноз лоя → следующий хай).
- **bias** = mean(pred_ratio − actual_ratio); положительный → переоценка.
- **rMAE** = mean|pred_ratio − actual_ratio| / mean|Δratio|.
- **M0** — случайное блуждание (предсказать текущее значение).

## 3. Методология

Walk-forward (каузальный):
- Тест: пивоты 203…850, n=647.
- S-map: theta=8, признаки `[z[i], Δz[i], ..., Δz[i-p+2]]`, горизонт H=1.
- Пул: SBER 1d+1h+10m (фрактальный пулинг); стандартизация ratio по таймфрейму.
- TRAIN_WIN=200 предшествующих пивотов первичного ряда (граница causal).
- Условия: 3 варианта фильтрации × 2 значения p = 6 условий.

## 5. Критика постановки

1. **Пул режется ровно пополам**: same_dir и opp_dir получают ~736 точек vs ~1471 у base — часть деградации объясняется уменьшением выборки, а не качеством сигнала.
2. **Направление зависит от предыдущего пивота** — признак, который уже есть в векторе задержек. Фильтрация по нему может дублировать информацию, уже учтённую S-map.
3. **Только SBER** — результат специфичен для одного инструмента.

## 7. Анализ и выводы

**Г1 отклонена**: same_dir хуже base на ~1% rMAE. Фильтрация по направлению убирает половину пула без информационного выигрыша — смешанный пул работает лучше.

**Г2 подтверждена**: opp_dir катастрофичен (rMAE ~1.9–2.0). Это санити-чек: пивоты противоположного направления — ложные соседи в пространстве задержек, а не информативный контрпример.

**Г3 частично подтверждена**: same_dir снижает разницу bias_H−bias_L (0.014 vs 0.020 при p=2), но не устраняет асимметрию. Проблема структурная для линейного S-map, не решается фильтрацией.

**Г4 подтверждена**: p=3 даёт −1.1% rMAE у base (лучший результат серии: 0.5332, −46.9% от M0). При same_dir выигрыш от p=3 почти исчезает.

**Главный вывод**: раздельные модели up/down не работают. Оптимум — base с p=3.

## 8. Дальнейшие направления

- Продолжить поиск оптимального p: проверить p=4, p=5 для base.
- Исследовать theta: при p=3 оптимальный theta может отличаться от 8.
- Ассиметрия H3 — структурная проблема линейного S-map; адресовать через нелинейные ядра или квантильную регрессию.
- Проверить результаты на втором тикере (LKOH).
