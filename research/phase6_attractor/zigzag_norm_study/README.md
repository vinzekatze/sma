# Zigzag Norm Study: сравнение нормализаций для зигзаг-прогноза

## 1. Гипотезы

- Г1: logtrend-нормализация (ratio) оптимальна для зигзаг-S-map; отказ от неё ухудшает прогноз.
- Г2: Swing-нормализация (swing_pct / log_swing) снижает систематическую переоценку уровня (H3-асимметрия).
- Г3: Локальный z-score ratio устраняет нестационарность и улучшает точность.

## 2. Концепции, терминология, обозначения

- **Пивот** — подтверждённый экстремум зигзага (T=2%).
- **z[i]** — значение ряда на пивоте i; зависит от варианта нормализации.
- **ratio** = `close[i] / logtrend[i]` — нормировка на каузальный логарифмический тренд.
- **raw** = `close[i]` — сырая цена без нормировки.
- **swing_pct** = `(close[i] − close[i−1]) / close[i−1]` — относительная амплитуда свинга.
- **log_swing** = `log(close[i] / close[i−1])` — логарифмический свинг.
- **ratio_zscore** = `(ratio[i] − mean(ratio[-W:])) / std(ratio[-W:])`, W=100 пивотов.
- **rMAE** = `mean|pred_ratio − actual_ratio| / mean|Δratio|` — относительная ошибка в ratio-пространстве.
- **CV** = `std(|err|) / mean(|err|)` — коэффициент вариации абсолютной ошибки.
- **Worst10%** = 90-й перцентиль ошибки в рублях.
- **Rolling std rMAE** (w=30) — std скользящего rMAE; показывает нестабильность ошибки во времени.
- **H3-асимметрия**: `bias_up` (прогноз к хаю) vs `bias_down` (прогноз к лою); у ratio `bias_down` систематически положительный (переоценка уровня).

## 3. Методология

Walk-forward (каузальный):
- Тест: pivot 202…N−1 (TRAIN_WIN=200 предшествующих пивотов).
- S-map: theta=8, p=2, признаки `[z[i], Δz[i]]` для level-вариантов; `[z[i], z[i−1]]` для swing-вариантов.
- Augmentation: SBER — пул 1d+1h+10m; LKOH — только 1d.
- Все прогнозы конвертируются в ratio-пространство через `trend_cur` (trend на баре текущего пивота) для единообразного сравнения.

## 4. Параметры

| Параметр | Значение |
|---|---|
| THRESH (T) | 0.02 (2%) |
| TRAIN_WIN | 200 пивотов |
| THETA | 8.0 |
| P (признаков) | 2 |
| H (горизонт) | 1 пивот |
| ZSCORE_W | 100 пивотов |
| Тикеры | SBER (1d+1h+10m), LKOH (1d) |

## 5. Критика постановки

1. **Trend для восстановления**: используется `trend[bar_step]`, а не `trend[bar_step+H]` (неизвестен). Вносит небольшую систематическую погрешность в ratio-метрику для вариантов raw/swing/zscore; для ratio-варианта погрешности нет.
2. **ratio_mean(SBER) = 1.11**: logtrend недооценивает долгосрочный рост SBER → ratio нестационарен. Это объясняет, почему raw-вариант оказывается конкурентным.
3. **ratio_zscore**: rolling stats вычисляются на последних W пивотах, что создаёт несопоставимые z-значения между разными шагами обучающего пула — одна из причин плохих результатов.
4. **Пул 1h/10m для swing-вариантов**: свинги разных таймфреймов имеют разные типичные амплитуды; модель смешивает паттерны из разных временных масштабов.

## 6. Результаты

### rMAE (ratio-space)

| Вариант | SBER | vs ratio | LKOH | vs ratio |
|---|---|---|---|---|
| M0 (random walk) | 0.999 | — | 0.999 | — |
| raw | **0.524** | **−2.0%** | 0.543 | +0.1% |
| log_swing | 0.535 | −0.9% | **0.538** | **−0.2%** |
| swing_pct | 0.540 | −0.4% | **0.537** | **−0.3%** |
| ratio (BASE) | 0.544 | 0.0% | 0.549 | 0.0% |
| ratio_zscore | 0.704 | +29.4% | 0.596 | +8.5% |

### Стабильность ошибок (SBER, цены в рублях)

| Вариант | CV | Worst10%, руб. | Rolling std rMAE |
|---|---|---|---|
| ratio_zscore | **1.137** | 17.1 | 0.397 |
| swing_pct | 1.343 | **11.6** | 0.295 |
| log_swing | 1.351 | **11.5** | 0.294 |
| ratio | 1.363 | 12.0 | **0.277** |

### H3-асимметрия (bias по направлению, ratio-space)

| Вариант | SBER bias_up | SBER bias_down | LKOH bias_down |
|---|---|---|---|
| ratio | −0.00620 | +0.01356 | +0.00123 |

Swing-варианты снижают `bias_down` примерно вдвое на SBER; на LKOH H3-асимметрия почти исчезает.

## 7. Анализ и выводы

**Г1 отклонена**: raw-прогноз без нормализации лучше ratio на SBER (−2%), сопоставим на LKOH. Нормализация через logtrend не даёт преимущества, потому что ratio_mean(SBER)=1.11 — сам ряд нестационарен внутри обучающего окна.

**Г2 частично подтверждена**: swing_pct/log_swing снижают H3-асимметрию (bias_down) на SBER вдвое, на LKOH убирают полностью. Однако rMAE улучшается незначительно (~0.4−0.9%), и временна́я стабильность не превосходит ratio.

**Г3 отклонена**: ratio_zscore даёт низкий CV (=«предсказуемо плохой»), но не лучшую точность. Rolling std rMAE у ratio_zscore наихудший. Локальный z-score создаёт несопоставимые значения между шагами пула.

**Главный вывод**: разница между нормализациями невелика (2−3% rMAE). Проблема H3-асимметрии частично снимается swing-вариантами, но полностью не устраняется — она структурная для линейного S-map. Логика подсказывает, что адресовать асимметрию стоит на уровне модели (отдельные модели up/down), а не нормализации.

## 8. Дальнейшие направления

- Проверить intrinsic dimensionality (TwoNN/FNN) аттрактора отдельно для up-пивотов и down-пивотов → обоснование отдельных моделей.
- Отдельные S-map-модели для up и down: если размерности разные, оптимальные p тоже разные.
- Для SBER дополнительно обновить данные и проверить, улучшится ли ratio (ratio_mean → 1.0 при свежем тренде).
