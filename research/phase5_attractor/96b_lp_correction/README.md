# 96b — LP-коррекция траектории (worst-40 origins)

## 1. Гипотезы

H1: LP-проекция предсказанной точки обратно на многообразие аттрактора снижает ошибку LWR-прогноза на горизонте H=1.

H2: LP-коррекция предотвращает экспоненциальное расхождение рекурсивных LWR-траекторий (видимое на H>5).

H3: Эффект коррекции наиболее выражен на изначально плохих прогнозах (worst-40 origins).

## 2. Концепции, терминология, обозначения

- **att**: сигнал аттрактора = `diff(LP_filter(ratio))`, где `ratio = close / exp(logtrend)`
- **LWR (Locally Weighted Regression)**: МНК с Гауссовыми весами по расстоянию в фазовом пространстве; ядро acc_ang λ=0.01
- **rMAE**: нормированная MAE = `MAE(att_pred, att_true) / std(att_full)`
- **H**: горизонт прогноза в барах (рекурсивный режим)
- **worst-40 origins**: 40 originsс наибольшим H=1 rMAE без LP-коррекции (выбираются из 200 origins)
- **LP-проекция (Local Projective correction)**:
  1. Формируем вектор `v = [context[-(m-1):], pred_raw]` — контекст + предсказанная точка
  2. Находим k ближайших соседей в библиотеке m-мерных векторов из обучающего att
  3. SVD соседей → локальная d-мерная плоскость аттрактора (d главных компонент)
  4. Проецируем v на эту плоскость → скорректированная предсказанная точка

**Параметры:**
- `M_LP = 9` — размерность векторов (совпадает с m LP-фильтра)
- `K_PROJ = 30` — число соседей (совпадает с k LP-фильтра)
- `D_PROJ = 3` — размерность локального многообразия (совпадает с d LP-фильтра)
- `n_iter = 1` — однократная проекция

## 3. Методология и протокол

**Данные:** SBER 1d, 4500 баров.

**Walk-forward схема:**
- N=40 worst origins из 200 равноотстоящих origins (шаг=5 баров)
- Для каждого origin — рекурсивный прогноз на H=1..20 шагов
- Два варианта: `lwr` (без коррекции) и `lp` (с LP-коррекцией)
- Метрика: rMAE по горизонту

**Каскад LWR:** P_FIT=16, P_MAX=64, ×2, ξ=51, acc_ang λ=0.01.

**Выбор worst-40:** сначала прогоняются все 200 origins без коррекции, отбираются 40 с наибольшим H=1 rMAE.

**LP-библиотека:** матрица `X_lib[N_lib × M_LP]` из обучающего att (до origin), построена до начала рекурсии (фиксирована).

## 5. Критика постановки

- **Только worst-40**: выборка смещена в сторону сложных origins — эффект на средних прогнозах неизвестен (проверено в 96c).
- **LP-библиотека фиксирована**: соседи не обновляются при рекурсии. Это корректно (causal), но при больших H контекст уходит за пределы обученного многообразия.
- **n_iter=1**: одна итерация проекции. Большее число итераций может либо улучшить «прилипание» к аттрактору, либо привести к коллапсу к локальному минимуму.
- **Параметры коррекции = параметры фильтра**: логично (одно пространство), но не верифицировано, что для коррекции не нужен другой m/k/d.
- **Только SBER 1d**: обобщение на другие тикеры не проверено.

## 6. Результаты

### rMAE по горизонту (N=40 worst origins)

| H | LWR | LP-коррекция | Улучшение |
|---|---|---|---|
| 1  | 0.641 | 0.462 | +28% |
| 2  | 2.276 | 1.186 | +48% |
| 5  | 6.693 | 1.445 | +78% |
| 10 | 29.22 | 1.188 | +96% |
| 15 | 75.41 | 1.429 | +98% |
| 20 | 577.6 | 1.438 | +99.75% |

LWR без коррекции: экспоненциальное расхождение до rMAE=577 к H=20.
LP-коррекция: рMAE стабилизируется в диапазоне 1.1–1.5 с H=4 по H=20.

Файлы: `results/summary.json`, `results/per_origin.jsonl`

## 7. Анализ и выводы

**H1 подтверждена**: H=1 улучшение +28% на самых плохих origins.

**H2 подтверждена** (полностью): расхождение полностью устранено. LWR расходится к rMAE≈577, LP стабилизируется на rMAE≈1.4. Механизм: каждый предсказанный шаг проецируется обратно на локальную плоскость аттрактора → предсказания остаются в «разрешённой зоне» многообразия.

**H3 частично подтверждена**: +28% на worst-40 vs +18% на всех 200 origins (96c). Эффект действительно выраженнее на трудных cases.

**Ключевой вывод**: LP-коррекция — обязательный компонент рекурсивного LWR-прогноза. Без неё за пределами H=3 прогноз теряет смысл.

## 8. Дальнейшие направления
