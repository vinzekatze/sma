# 97 — Параметры LP-фильтра: перебор (d_proj, m) по FNN-критерию

## 1. Гипотезы

1. FNN-кривая `dratio_filtered` опускается ниже 5% при разных `d_fnn` в зависимости от `m` и `d_proj` — т.е. LP-параметры меняют «наблюдаемую» размерность аттрактора.
2. Существует диапазон `(d_proj, m)`, при котором FNN сходится к стабильному `p_opt` независимо от лишних размерностей (`m_excess`).
3. Чрезмерное сглаживание (большой `m` при малом `d_proj`) ведёт к `var_ratio < 0.01` и искусственно низкому `p_opt`.

## 2. Концепции и обозначения

| Обозначение | Смысл |
|---|---|
| `ratio` | `close / logtrend` — нормализованная цена |
| `dratio` | `diff(ratio)` — сырые приращения |
| `d_proj` | Размерность локального подпространства аттрактора (LP-параметр) |
| `m` | Размерность вложения LP (`m ≥ 2·d_proj+1`, теорема Такенса) |
| `m_excess` | `m - (2·d_proj+1)` — «запас» сверх минимума по Такенсу |
| `k = 3m` | Число соседей для локальной PCA (гарантирует `k >> m`) |
| `n_iter = 3` | Число итераций LP |
| `dratio_filtered` | `diff(local_projective(ratio, m, d_proj, k, 3))` |
| `var_ratio` | `var(dratio_filtered) / var(dratio)` — диагностика сглаживания |
| `p_opt` | Первый `d_fnn`, при котором FNN-фракция < 0.05; 999 если не достигнут |
| `Theiler = m` | Исключение `m` баров вокруг точки в FNN (LP вносит авток. на ~m баров) |

## 3. Методология

- **Данные:** 8 тикеров MOEX × 1d, logtrend-нормализация (causal OLS).
- **LP-фильтр** (Grassberger-Hegger 1993): каждая точка `m`-мерного вложения проецируется на локальное `d_proj`-мерное подпространство (PCA по `k` ближайшим соседям), затем диагональное усреднение.
- **FNN:** алгоритм Кеннела (1992) на `dratio_filtered`; два критерия: расстояние (`r_tol=10`) и амплитуда (`a_tol=2`); Theiler=m, tau=1.
- **Перебор:** по каждому тикеру независимо; результаты хранятся per-ticker.

## 4. Параметры

| Параметр | Значение |
|---|---|
| `d_proj` | 2..15 (14 значений) |
| `m_excess` | 0..10 (11 значений) → `m = 2d+1..2d+11` |
| Конфигов | 154 на тикер × 8 тикеров = 1232 |
| `k` | `3m` (адаптивный) |
| `n_iter` | 3 |
| `FNN D_MAX` | 20 |
| `FNN Theiler` | `m` (адаптивный) |
| `FNN_THR` | 0.05 |
| Тикеры | CHMF LKOH MGNT MRKP NLMK NVTK SBER VTBR |
| Интервал | 1d |

## 5. Критика постановки

1. **Чрезмерное сглаживание ≠ найденный аттрактор.** При большом `m` и малом `d_proj` LP превращает ряд в монотонный сигнал → FNN тривиально падает до 0 уже при `d_fnn=1`. `var_ratio` диагностирует этот случай.

2. **`k=3m` одновременно меняет число соседей и их плотность.** При росте `m`: (а) пространство вложения расширяется, (б) `k` растёт, делая локальную PCA «глобальнее». Эти два эффекта неразделимы в данном эксперименте.

3. **FNN на `dratio` vs `ratio`.** Из фазы 2 известно: raw `dratio` стохастичен (FNN не убывает), raw `ratio` имеет аттрактор при `p≈4`. Эксперимент проверяет, насколько LP «детерминирует» `dratio`. Если `p_opt` оказывается 1 — это эффект сглаживания, а не аттрактора.

Запущен частичный прогон: 2 тикера (SBER, CHMF), d_proj=2..5, m_excess=0..5 (48 конфигов).
Полный прогон остановлен досрочно — картина определилась уже на первых d.

- CSV: `results/fnn_grid.csv` (48 строк)

**p_opt (медиана SBER+CHMF):**

```
d_proj  +0  +1  +2  +3  +4  +5
d=2      4    4    4    4    4    3
```

**var_ratio:** 0.12–0.27 (LP убирает 73–88% дисперсии, чрезмерного сглаживания нет — порог 0.01 не достигнут ни разу).

FNN-кривые чистые: монотонный спад от 0.99 (d_fnn=1) до ~0.01–0.05 (d_fnn=4).

## 7. Анализ и выводы

**Главный результат: p_opt = 3–4 при любых (d_proj, m_excess) в исследованном диапазоне.**

LP-фильтр надёжно изолирует аттрактор размерности ~4 при любых разумных параметрах. Это согласуется с фазой 2 (ratio имеет аттрактор при p≈4). Однако параметры LP на это практически не влияют — FNN не умеет различать «лучший» и «худший» конфиг.

**FNN как критерий выбора LP-параметров не работает.** Продолжение перебора до d_proj=15 не даст новой информации.

**Вывод по критике:** опасение №3 (чрезмерное сглаживание → артефактная низкая размерность) не подтвердилось при var_ratio > 0.12. Опасение №1 было точным: FNN одинаково реагирует на всё разнообразие параметров.

## 8. Дальнейшие направления

FNN-подход к выбору LP-параметров закрыт. Единственный честный критерий — **rMAE walk-forward**. Именно через него нужно оптимизировать (m, d_proj, k, n_iter) — отдельным экспериментом.
