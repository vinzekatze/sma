# 96c — LP-коррекция на всех 200 origins + ценовой MAPE

## 1. Гипотезы

H1: LP-коррекция улучшает rMAE не только на worst-40, но и на средних/хороших origins (обобщение 96b).

H2: LP-коррекция улучшает MAPE на уровне цен (не только att-ошибку).

H3: Эффект LP-коррекции растёт с горизонтом (предотвращение расхождения).

## 2. Концепции, терминология, обозначения

- **att**: сигнал аттрактора = `diff(LP_filter(ratio))`
- **lp_ratio**: сглаженный LP-фильтром `ratio` (до diff); используется как база реконструкции цены
- **rMAE**: `MAE(att_pred, att_true) / std(att_full)` — нормированная MAE на пространстве att
- **MAPE**: `mean(|price_pred - price_true| / price_true)` — ошибка на уровне исходных цен (SBER руб.)
- **LP-коррекция**: проекция предсказанной точки att на локальную d-мерную плоскость аттрактора (см. 96b)
- **Реконструкция цены**:
  1. `att_pred → lp_ratio_hat = lp_ratio[origin+1] + cumsum(att_pred)`
  2. `price_hat = lp_ratio_hat × logtrend[origin+2:]`

**Параметры совпадают с 96b**: M_LP=9, K_PROJ=30, D_PROJ=3, n_iter=1.

## 3. Методология и протокол

**Данные:** SBER 1d, 4500 баров.

**Walk-forward схема:**
- N=200 origins, шаг=5 баров (все без отбора по качеству)
- Рекурсивный прогноз H=1..20 для каждого origin
- Два варианта: `lwr` (без коррекции) и `lp` (с LP-коррекцией)
- Метрики: rMAE(att) и MAPE(price)

**Каскад LWR:** P_FIT=16, P_MAX=64, ×2, ξ=51, acc_ang λ=0.01.

**LP-библиотека:** строится из обучающего att до каждого origin (causal).

## 5. Критика постановки

- **SBER 1d only**: все выводы — для одного тикера; обобщение на GAZP/LKOH/NVTK не проверено.
- **P_REG = 16 фиксирован**: не ensemble, не LOO-select. Эффект LP-коррекции при ensemble (p∈[4..16]) неизвестен — может быть иным.
- **n_iter=1**: практически принятое значение; теоретически оптимальное число итераций не исследовалось.
- **MAPE vs att**: реконструкция через cumsum накапливает ошибку. MAPE содержит компоненту логтренда (умножение) — небольшая att-ошибка даёт меньшую MAPE при восходящем тренде.
- **LP-библиотека**: включает обучающие данные до origin, но при H=20 контекст заходит в «будущее» через рекурсию — соседи могут не соответствовать реальным паттернам.

## 7. Анализ и выводы

**H1 подтверждена**: +17.6% rMAE на H=1 по всем 200 origins (vs +28% на worst-40 в 96b). Эффект устойчив на средних origins.

**H2 подтверждена**: MAPE на H=1 улучшается на 7.5%, на H=5 — на 59%. Ценовой прогноз также выигрывает.

**H3 подтверждена**: Δ монотонно растёт с H. При H=1 LP выигрывает в 68% origins, при H=20 — в 99%.

**Ключевые наблюдения:**
- LP-коррекция стабилизирует rMAE в диапазоне 0.96–1.29 для H=5..20 (LWR уходит в 216)
- MAPE LP при H=20: 11% vs 430% у LWR — разница 40-кратная
- На H=1 эффект скромнее (+7.5% MAPE), но значим — это горизонт реального использования

**LP-коррекция принята как стандартный компонент рекурсивного прогноза att.**

## 8. Дальнейшие направления

### Приоритетные (обозначены по итогам 96a-96c)

1. **Оптимальные глобальные настройки LP** (m, k, d): текущие m=9, k=30, d=3 наследованы из att-фильтра; нет исследования оптимума для комбинации фильтр+корректор+прогноз.

2. **Взаимосвязь p_reg и настроек LP**: как m фильтра определяет «физический масштаб» и как это связано с оптимальным p_reg? Возможно, m задаёт масштаб, а p_reg должен быть согласован с ним.

3. **Пути выбора оптимального p_reg per-origin**: oracle даёт −53% rMAE, текущий ensemble −12.4%. Щель огромная. Нужен предиктор p_reg из свойств att-траектории (локальная размерность, кривизна, ...)

### Прочие направления

- **Ensemble с LP-коррекцией**: LP работает с fixed p=16. При ensemble p∈[4..16] плюс LP-коррекция — суммируется ли эффект?
- **Другие тикеры**: обобщение GAZP, LKOH, NVTK
- **LOO-select + LP**: возможно LP стабилизирует траектории настолько, что LOO-ошибки становятся информативнее
- **GARCH на noise-компоненте**: параллельно прогнозу att (независимая задача)
