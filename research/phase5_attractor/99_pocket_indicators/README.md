# 99 — Индикаторы качества «кармана» локального аттрактора

## 1. Гипотезы

**H1:** Области фазового пространства с хорошим прогнозом att имеют измеримые геометрические свойства.

**H1a (ρ(A)):** В «хороших» карманах локальный поток сжимающийся (ρ(J) < 1). Ожидаем ρ(A) отрицательно коррелирует с test_rMAE (меньше ρ → лучше прогноз).

**H1b (d_L):** В «хороших» карманах локальная размерность аттрактора ниже p_fit. Ожидаем d_L отрицательно коррелирует с test_rMAE (меньше d_L → лучше прогноз).

**H1c (DET):** В «хороших» карманах область детерминированна — высокий DET. Ожидаем DET отрицательно коррелирует с test_rMAE.

**H1d (LOO-MAPE):** LOO-ошибка LWR является прокси для качества прогноза. Ожидаем положительную корреляцию LOO-MAPE ↔ test_rMAE.

## 2. Концепции, терминология, обозначения

| Термин | Определение |
|--------|-------------|
| **att** | Сигнал аттрактора: `np.diff(LP(ratio))`, LP-фильтр на скользящем окне LP_W баров |
| **Causal LP** | LP применяется к `ratio[t-LP_W+2 : t+2]` — данные после origin не используются |
| **att_local** | att на окне LP_W-1 значений, заканчивающемся в t_orig (длина 599) |
| **att_point[t]** | Последний элемент att_local при origin=t (скалярное значение att в момент t) |
| **Библиотека** | 590 задержанных окон att размером P_FIT=9, построенных из att_local |
| **query** | Текущее состояние в R^9: att_local[-9:] |
| **k_ind-соседи** | K_IND=50 ближайших соседей по L2 в att-пространстве (для TwoNN и DET) |
| **xi-соседи** | XI=35 ближайших соседей по acc_ang-метрике (для LWR и якобиана) |
| **ρ(A)** | Спектральный радиус companion-якобиана LWR. J[0,:] = c[1:] (коэф. LWR), J[1:,:-1] = I |
| **d_L (TwoNN)** | Локальная размерность: d̂ = (k−1)/Σln(r₂/r₁) на 50 соседях |
| **DET** | Determinism: доля рекурр. точек на диаг. линиях длиной ≥ 2 (ε = 20-й перц.) |
| **LOO-MAPE** | Leave-one-out MAPE LWR на xi=35 acc_ang-соседях |
| **test_rMAE** | MAE(прогноз, att_actual) / MAE(naive_last, att_actual), горизонт 10 баров |
| **naive_last** | Повтор att_local[-1] на все 10 шагов |

## 3. Методология и протокол

**Walk-forward:** для каждого origin t (последние 100 баров каждого тикера):
1. Causal LP на `ratio[t-600+2 : t+2]` → att_local (599 значений)
2. Библиотека: 590 окон × 9 dim + 590 целей y
3. Поиск соседей: K_IND=50 по L2 (для индикаторов), XI=35 по acc_ang (для LWR)
4. Вычисление 4 индикаторов
5. Рекурсивный LWR-прогноз на 10 шагов (с acc_ang λ=0.01)
6. Сравнение с att_actual[t+1..t+10], полученным из causal LP в каждой точке независимо
7. Запись в CSV

**Анализ:** ранговая корреляция Спирмена каждого индикатора с test_rMAE (глобально и per-ticker).

## 5. Критика постановки

**Look-ahead check:**
- LP фильтр применяется к `ratio[:t+2]` → данные после t не используются ✓
- att_point[t+h] для test_rMAE — из LP на окне, заканчивающемся t+h → каузально ✓
- Библиотека, query, соседи — из att_local (data до t включительно) ✓
- **Ограничение внутри окна:** rolling-window LP некаузален внутри окна (соседи включают «ближайшее будущее» относительно ранних позиций окна). Это компромисс между каузальностью и вычислительной стоимостью полного per-position causal LP.

**Методологические риски:**
1. **Несогласованность att:** att_local (из LP на окне t) и att_actual (из LP на окне t+h) — разные LP-прогоны. Незначительное различие шкал может добавлять шум в test_rMAE.
2. **Нет каскада:** LWR использует простой acc_ang-поиск без октавного каскада → качество прогноза ниже стандартного; test_rMAE выше, чем в скр.85-86.
3. **Короткая библиотека:** только 590 точек из LP_W=600 (vs тысячи в стандартном пайплайне). Ограничивает качество поиска соседей.
4. **LOO-MAPE ≠ val_mape:** стандартный val_mape считается на отдельном val_origin; здесь — LOO на тех же xi-соседях, что и LWR. Это более шумная оценка.
5. **Origins не независимы:** 100 последовательных точек высоко автокоррелированы. Stdr.ошибка Spearman-r занижена.

## 7. Анализ и выводы

### H1a (ρ(A) якобиан): **Отклонена**

r≈0 во всех трёх режимах. Знак нестабилен по тикерам. Companion-якобиан при
XI=35, P_FIT=9 численно нестабилен (матрица 9×9, минимальная регуляризация).

### H1b (d_L TwoNN): **Отклонена**

Знак корреляции меняется между режимами: −0.090 (lp600) → +0.042 (lp2000) →
+0.073 (longhist). Это не случайное варьирование одного сигнала — это разные
знаки у разных физических объектов (разные библиотеки, разные пространства).
Дополнительная проверка показала: dratio без LP даёт d_L≈9 (нет структуры),
att после LP даёт d_L≈3-5. **LP создаёт аттрактор, а не обнаруживает его.**

### H1c (DET RQA): **Отклонена со знаком, обратным теоретическому**

В longhist: r=+0.167, 7/8 тикеров положительны. Но ожидалось отрицательное
значение (высокий DET → лучший прогноз → ниже rMAE). Реальный результат:
высокая рекуррентность 50 соседей → они почти идентичны → LWR вырождается
из-за нехватки вариабельности в матрице X_nn → хуже прогноз.

### H1d (LOO-MAPE): **Слабо поддержана, практически незначима**

r≈+0.07-0.10 во всех режимах, 7/8 тикеров положительны для lp600/lp2000.
Правильный знак, но сигнал слишком слабый для использования в качестве gate.
Стандартный val_mape (фаза 1: r=0.51) принципиально сильнее — он использует
отдельное val-окно, а не LOO на тех же соседях.

### Общий вывод

**Геометрические индикаторы кармана не работают.** Сигнал везде слабый (|r| < 0.17),
нестабильный по знаку и режимам. Две фундаментальные причины:

1. **LP создаёт аттрактор:** структура, которую мы измеряем, является артефактом
   самого фильтра, а не свойством данных. Поэтому геометрия att-окрестности не
   несёт independent информации о качестве прогноза.

2. **Несогласованность att_actual:** att_actual[t+h] из LP-окна [t+h-598:t+h+2]
   несовместим по фазе/шкале с att_forecast, построенным от LP-окна [t-598:t+2].
   Это шум в целевой переменной, не зависящий от качества индикаторов.
