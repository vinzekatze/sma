История прогнозов

Прогноз диапазона
Прогноз коридора min(low)..max(high) на h=1..H шагов вперёд, БЕЗ прогноза точки close — живой предпросмотр, пересчитывается при смене origin/настроек. Клик по графику ставит точку отсчёта (origin); без клика — от последнего доступного бара.
Для этой комбинации H/p/theiler ещё нет калибровки — прогноз не показан. Нажмите «Калибровать» ниже, либо переключитесь на «По умолчанию».

Метод

Зоны вероятности

Каждый чекбокс — центральный интервал вокруг close (напр. «50%» = средние 50% исходов). Включённые зоны накладываются друг на друга — узкая гуще в центре.

Калибровка θ+признаков

Многопроходный координатный спуск (θ + 5 λ-признаков: объём/тренд/скорость/ускорение/волатильность) + подбор квантиля чтения на каждый уровень, честная проверка на отложенной выборке. ~30-40с на дневных данных.
Риск-корридор
Риск-огибающая High/Low (running max/min) + полоса Close на h=1..H шагов вперёд — живой предпросмотр, пересчитывается при смене origin/настроек. Клик по графику ставит точку отсчёта (origin); без клика — от последнего доступного бара. Метод: kNN по форме Δratio + Student-t кернель + Monte Carlo, без калибровки — параметры глобальны и устойчиво обобщаются на новые тикеры.
95%
Уровень, ДОСТИГНУТЫЙ ценой к шагу h (max High / min Low за весь путь до h) — риск-релевантно для стопов. Управляет ОБЕИМИ огибающими разом (полоса Close и риск-огибающая High/Low).
Кернель — Student-t, nu=1.0 (фиксирован, не настраивается).
