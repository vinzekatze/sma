# другое

Отличная тема — это фундаментально важный вопрос для LA: метод работает именно тогда, когда система порождает
  детерминированный хаос низкой размерности. Вот обзор по направлениям.

  ---
  Теоретическое основание LA

  LA опирается на теорему Такенса (1981): скалярный временной ряд детерминированной хаотической системы позволяет
  реконструировать её аттрактор через матрицу задержек. Ключевое условие — система должна быть детерминированного, а не
  стохастического хаоса.

  Это сразу даёт нам критерии: нужно отличить детерминированный хаос от шума.

  ---
  Признаки детерминированного хаоса

  1. Корреляционная размерность D₂ (Grassberger–Procaccia)

  Самый прямой индикатор пригодности для LA.

  - Вычисляется как: как часто пары точек в фазовом пространстве попадают в шар радиуса r
  - D₂ конечная и нецелая → детерминированный хаос → LA применим
  - D₂ растёт с длиной ряда → скорее случайный процесс → LA бессмысленен
  - Практически: для финансов ожидаем D₂ ≈ 2–5 в "хаотических" участках

  Связь с параметром p: оптимальная размерность вложения m ≥ 2·D₂ + 1 (теорема Такенса). Если D₂ = 2.5, то m = 6 — это
  верхняя граница для перебора p.

  ---
  2. Максимальный показатель Ляпунова (MLE)

  - MLE > 0 → хаос, чувствительность к начальным условиям
  - MLE = 0 → граница хаоса (периодическая/квазипериодическая система)
  - MLE < 0 → стабильная система, нет хаоса

  Критически важно для горизонта прогноза:

  T_forecast_max ≈ 1 / MLE

  Если MLE большой — горизонт прогноза мал. Это объясняет, почему для некоторых участков прогноз на horizon=10 заведомо
  бесполезен.

  ---
  3. False Nearest Neighbors (FNN)

  Метод определения минимальной размерности вложения m:

  - Берём ближайшего соседа в пространстве размерности m
  - Если при переходе m → m+1 сосед "убегает далеко" — он был "ложным" (случайный артефакт проекции)
  - FNN → 0% при правильном m

  Прямая польза: автовыбор p вместо текущего перебора. Также: если FNN не падает до нуля — система скорее
  стохастическая.

  ---
  4. Recurrence Quantification Analysis (RQA)

  Быстрый и устойчивый способ оценить детерминированность:

  ┌─────────────────────────┬────────────────────────────────────────────────┬─────────────────────┐
  │         Метрика         │                     Смысл                      │ Порог "LA применим" │
  ├─────────────────────────┼────────────────────────────────────────────────┼─────────────────────┤
  │ DET (determinism)       │ доля точек на диагоналях RP                    │ > 0.6–0.7           │
  ├─────────────────────────┼────────────────────────────────────────────────┼─────────────────────┤
  │ L (avg diagonal length) │ средняя длина детерминированных участков       │ > 3–5               │
  ├─────────────────────────┼────────────────────────────────────────────────┼─────────────────────┤
  │ LAM (laminarity)        │ доля вертикальных линий (ламинарные состояния) │ информативен        │
  └─────────────────────────┴────────────────────────────────────────────────┴─────────────────────┘

  DET напрямую показывает — насколько поведение системы детерминировано. Низкий DET → соседи в LA будут "плохими",
  прогноз ненадёжен.

  ---
  5. Surrogate Data Test (тест на нелинейность)

  Нулевая гипотеза: ряд — линейный стохастический процесс.

  1. Генерируем N суррогатных рядов (случайный фаз, сохранён спектр мощности — AAFT/IAAFT)
  2. Считаем нелинейную статистику (например, прогнозная ошибка LA на суррогатах vs. оригинале)
  3. Если оригинал значимо лучше → нелинейная структура существует

  Это единственный статистически строгий способ утверждать, что LA работает не случайно.

  Практическое предложение

  Наиболее перспективные кандидаты по соотношению ценность/сложность реализации:

  4. DET (RQA) — вычислительно дёшево, интерпретируем, нет свободных параметров кроме радиуса соседства
  5. FNN — убивает двух зайцев: и признак хаоса, и автовыбор p
  6. Surrogate test — наиболее статистически строгий, но дорогой (N суррогатов × время LA)
