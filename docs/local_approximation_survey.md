Обзор составлен на основе литературного поиска (июнь 2026).

## 1. Исходный метод — Farmer & Sidorowich (1987)

**Источник:** Farmer J.D., Sidorowich J.J. «Predicting chaotic time series» // Physical Review Letters. 1987. Vol. 59, P. 845–848.  
https://ui.adsabs.harvard.edu/abs/1987PhRvL..59..845F/abstract

Статья ввела базовую парадигму локального прогнозирования в фазовом пространстве:

1. Скалярный ряд `x(t)` вкладывается в фазовое пространство через задержки:
   ```
   X(t) = [x(t), x(t−τ), x(t−2τ), ..., x(t−(m−1)τ)]
   ```
2. Формируется библиотека векторов из истории ряда.
3. Для вектора запроса `X(t*)` ищутся k ближайших соседей `X(t_1), ..., X(t_k)` по L2-расстоянию.
4. По найденным соседям и их образам `x(t_i + h)` строится аппроксимация и делается прогноз на горизонт h.

### Два порядка аппроксимации

| Порядок | Название | Суть |
|---|---|---|
| 0 | **Zeroth-order** (локально-постоянный) | `ŷ = mean(x(t_i + h))` — простое среднее образов соседей |
| 1 | **First-order** (локально-линейный) | МНК-регрессия `ŷ = a + B·X(t*)` по соседям; B — матрица Якобиана |

Показана на примерах: уравнение Маки–Гласса, конвекция Рэлея–Бенара, течение Тейлора–Куэтта.

### Теорема Такенса (основа вложения)

Теорема Такенса (1981) гарантирует, что для любой наблюдаемой `h(x)` детерминированной системы размерности d достаточно вложения в размерность `m ≥ 2d + 1`, чтобы реконструировать аттрактор без потерь (диффеоморфизм). На практике `m` подбирается по методу ложных ближайших соседей (FNN) или критерию Рагвица.

## 2. Метод Symplex и S-map — Sugihara & May (Empirical Dynamic Modelling)

**Пакеты:** rEDM (R), pyEDM (Python)  
https://sugiharalab.github.io/EDM_Documentation/  
https://deepeco.ucsd.edu/nonlinear-dynamics-research/edm/

### 2.1 Simplex projection (zeroth-order, 1990)

Zeroth-order метод с фиксированным числом соседей: `k = E + 1` (минимум точек, окружающих запрос в E-мерном пространстве, без лишних параметров).

Веса по расстоянию:
```
w_i = exp(−d_i / d_1)   (d_1 — расстояние до ближайшего соседа)
ŷ = Σ w_i · x(t_i + h) / Σ w_i
```

Параметр числа соседей не настраивается — он жёстко равен E+1. Свободный параметр — только E.

### 2.2 S-map (нелинейный, 1994)

Вместо k соседей — **все** точки библиотеки с экспоненциально убывающими весами:
```
w_i = exp(−θ · d_i / d̄)   (d̄ — среднее расстояние по библиотеке)
```
Затем МНК-регрессия с этими весами → локально-линейная аппроксимация.

Параметр `θ` — «степень нелинейности»:
- θ = 0: глобальная линейная регрессия (все точки с равными весами)
- θ → ∞: только ближайшие соседи (как Simplex)
- Оптимальный θ > 0 → сигнал нелинеен

Диагностическое правило: если ошибка минимальна при малых окрестностях (θ >> 0) — система нелинейная; при θ ≈ 0 — линейная или стохастическая.

### 2.3 Convergent Cross Mapping (CCM)

Метод для определения причинно-следственных связей. Если X причинно влияет на Y, то по реконструкции из Y можно предсказать X, причём качество предсказания растёт с объёмом библиотеки (convergence). Позволяет различить корреляцию и причинность в слабосвязанных нелинейных системах.

### 2.4 Multiview Embedding

Строится ансамбль из C(n_vars, E) возможных вложений из мультивариатного ряда; выбираются E² лучших по ρ на валидации и усредняются. Даёт устойчивость при неправильном выборе переменных и к шуму.

**Реализация:** rEDM::Multiview(), pyEDM Multiview()

## 3. Локально-проективная коррекция (GHKSS / LP-фильтр)

**Источник:** Hegger R., Kantz H., Schreiber T. «Practical implementation of nonlinear time series methods: The TISEAN package» // Chaos. 1999. Vol. 9. P. 413.  
https://arxiv.org/pdf/chao-dyn/9810005

**Расширение с нелинейными ограничениями:**  
https://arxiv.org/pdf/cond-mat/0308554

### Основная идея

Детерминированный сигнал лежит на низкоразмерном многообразии в пространстве вложения. Шум смещает реальные наблюдения с этого многообразия. GHKSS итеративно проецирует векторы задержек обратно на многообразие:

```
Для каждого вектора X(t):
  1. Найти k соседей {X(t_i)}
  2. Вычислить центр масс: μ = mean(X(t_i))
  3. SVD матрицы (X(t_i) − μ): разложить на d главных компонент
  4. Проецировать X(t) − μ на d-мерное подпространство
  5. Скорректированный вектор: X̃(t) = μ + Vd · Vd^T · (X(t) − μ)
  6. Повторять n_iter раз
```

Параметры: m (размер вектора), d (размерность многообразия), k (число соседей), n_iter.

Это именно LP-фильтр, используемый в данном проекте для выделения att. Параметры: m=9, d=3, k=30, n_iter=1 (значение n_iter≥2 вызывает утечку из будущего для causal-применения).

## 4. Обобщение МЛА через SSA — Loskutov, Istomin, Kotlyarov (2001)

**Источник:** Loskutov A., Istomin I., Kotlyarov O. «Data Analysis: Generalisations of the Local Approximation Method by Singular Spectrum Analysis».  
https://arxiv.org/pdf/nlin/0109022

### Идея

SSA (Singular Spectrum Analysis) разлагает ряд через SVD матрицы задержек на компоненты (тренд, осцилляции, шум). Авторы предлагают применять МЛА не к исходному ряду, а к SSA-реконструированному сигналу (после отфильтровки шумовых компонент).

### Результат

Расширяет применимость МЛА на сильно зашумлённые сигналы. Позволяет прогнозировать ряды, где прямое применение МЛА даёт плохой результат из-за шума.

## 5. Prediction in Projection (PiP) — Gilpin (2018)

**Источник:** arXiv:1805.07360  
https://arxiv.org/pdf/1805.07360

### Идея

Вместо вложения в полное m-мерное пространство — прогноз в проекции на подпространство меньшей размерности. Для частично наблюдаемых систем это позволяет:
- Избежать «проклятия размерности» при высоком m
- Работать с неполными наблюдениями (не все переменные системы измеряются)

Теоретически обосновывается: проекция сохраняет предсказательную силу при определённых условиях на систему.

## 6. Ансамбль субоптимальных вложений — Ding et al. (2019)

**Источник:** arXiv:1907.01552  
https://arxiv.org/abs/1907.01552

### Идея

Вместо поиска «единственного правильного» вложения — строится ансамбль из многих субоптимальных вложений (разные τ, m, наборы переменных при мультивариатном ряде).

```
Алгоритм:
  1. Сгенерировать N вложений с разными (m_j, τ_j)
  2. Для каждого вложения запустить МЛА (Simplex/S-map)
  3. Усреднить предсказания лучших k вложений
```

Работает лучше одиночного вложения при высокой размерности системы и при шуме. Прямой аналог вашего sweep по d (перебор размерностей вложения).

## 7. LWR с адаптивной шириной ядра (k-LWR)

**Источник:** IEEE Conference «A k-nearest neighbor locally weighted regression method for short-term traffic flow forecasting»  
https://ieeexplore.ieee.org/document/6338648/

**Обзор:** https://arxiv.org/pdf/2103.14200

### Метод

```
1. Найти k ближайших соседей {X(t_i)} для запроса X(t*)
2. Gaussian-веса: w_i = exp(−0.5 · (d_i / h)²),  h = max(d_i)
3. МНК с весами: min_β Σ w_i · (y_i − β_0 − X_i · β)²
4. Предсказание: ŷ = β_0 + X(t*) · β
```

Ширина ядра h = расстояние до дальнего из k соседей — адаптивная (больше в разреженных областях, меньше в плотных). Именно эта схема используется в LWR-уровне каскада.

Модификации:
- **Фиксированная h:** ширина ядра — константа; все точки библиотеки участвуют (как S-map)
- **Adaptive h per dimension:** разные h по каждой оси (mahalanobis-вариант)
- **Robust LWR (LOWESS):** итеративно переwzвешивает, понижая влияние выбросов через bisquare-веса

## 8. Актуальные направления (2024–2025)

### 8.1 LETS Forecast — Learning Embedology (июнь 2026)

**Источник:** arXiv:2506.06454  
https://arxiv.org/html/2506.06454v2

Нейросеть обучается совместно подбирать параметры вложения (m, τ) и строить прогноз. Интегрирует теорему Такенса с архитектурами Transformer.

### 8.2 Nearest Neighbor Multivariate Time Series Forecasting (май 2025)

**Источник:** arXiv:2505.11625  
https://arxiv.org/abs/2505.11625

Retrieval-augmented подход: большой датастор кэшированных серий + kNN-поиск для дообогащения претренированной модели прогнозирования мультивариатных рядов. Не требует дообучения.

### 8.3 Dynamics-aware noise reduction (2026)

**Источник:** Springer Nonlinear Dynamics  
https://link.springer.com/article/10.1007/s11071-026-12517-5

Шумоподавление с учётом динамики системы — развитие идей GHKSS.
